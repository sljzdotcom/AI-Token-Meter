# macOS 悬浮条清透 Liquid Glass 规格

关联需求：REQ-20260914-003。日期：2026-09-14。状态：用户已批准推荐方案并进入实现。

## 目标行为

- macOS 的 Liquid Glass 悬浮条应明显透出其后的桌面内容，不再呈现整块灰黑底板。
- macOS 26及以上继续使用系统原生 Liquid Glass；只叠加极淡冷色 tint 和细边缘高光，不再叠加原 B 款高不透明度烟熏渐变。
- macOS 14–15继续使用`ultraThinMaterial`，只增加同一极淡冷色 tint，保持与新系统接近的清透感。
- 开启“降低透明度”时继续使用不透明深色回退，保证系统辅助功能偏好和圆环可读性。
- 展开态与折叠态共用相同材质规则；Comfortable/Compact、左右轮廓、圆环颜色、自动隐藏、拖动和点击行为保持现有合同。
- Deep Sea 外观与 Windows 产品行为不变。

## 视觉参数

清透 tint 使用冷蓝色，表面覆盖强度为12%。普通边界维持现有0.75pt、11%白色高光；开启高对比度或“不依赖颜色区分”时维持1.2pt、28%白色高光。窗口外形和面板尺寸不因材质调整。

不透明辅助功能回退继续使用现有深色渐变。该回退是用户明确请求降低透明度时的可读性行为，不作为普通 Liquid Glass 的显示结果。

## 验收

- 在明确关闭“降低透明度”的无背景真实 SwiftUI 渲染中，展开与折叠表面中心透明度低于30%，并仍高于10%，证明表面既清透又可见；辅助功能回退由独立材质策略测试覆盖。
- Liquid Glass不绘制Deep Sea图片；两档密度、左右边缘、展开与折叠轮廓继续通过渲染测试。
- 原生、旧系统和降低透明度三条材质选择路径保持正确。
- 完整Swift测试、macOS正式App构建、文档检查和独立审查通过；本次不发布新版本。
