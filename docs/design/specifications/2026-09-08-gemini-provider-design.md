## 建议及选择

建议首期采用 **Gemini CLI**，展示官方 CLI 确实返回的额度以及独立标注的本机活动，扩展双平台既有显示/排序设置。优先完成无模型调用的额度采集可行性验证，再确定自动额度功能是否能交付；不能取得额度时，不用本机 tokens 或文档中的套餐数值伪造百分比。

| 方案 | 优点 | 边界 | 建议 |
| --- | --- | --- | --- |
| A：CLI 优先，额度能力先验证 | 与 Claude Code/Codex 使用场景一致，可复用进程与状态框架 | 文档命令存在不等于能在全新会话自动取得可解析额度；需要限定支持版本 | 推荐 |
| B：API 项目监控 | 适合按项目用 API 的用户 | API Key、项目限流和订阅不是同一口径；全项目指标授权及采集另需设计，单次响应不是账户总量 | 后续独立范围 |
| C：Gemini 网页订阅额度 | 符合只用网页版的用户期待 | 本轮未找到供第三方读取个人剩余额度的公开接口，无法承诺自动采集 | 不作为首期自动接入 |

请求用户决定三项：首期是否采用 A；强调色采用青绿 `#3ED6B2`（推荐）还是玫红 `#F079A5`；旧用户升级后 Gemini 是否默认隐藏（推荐，用户勾选后显示）。这些决定由协调入口转述。若用户实际希望监控网页订阅，应重新确认范围，不能默认为 CLI 等价。

## 官方证据与数据口径

以下为公开资料核对，未读取或调用任何用户 Google 账号。网页与上游 main 源码会变化，实施前须固定受支持 CLI 版本及对应源码提交，并以该版本的输出样本验证。

| 来源 | 核对结论 | 对设计的约束 |
| --- | --- | --- |
| [CLI 额度说明](https://geminicli.com/docs/resources/quota-and-pricing/) | 认证方式和套餐影响额度；说明指向 `/stats model` 查看会话 tokens 与额度 | 不硬编码套餐上限；区分会话与账户、认证模式 |
| [命令参考](https://geminicli.com/docs/reference/commands/#stats) | `/stats` 默认 session，另有 model/tools | 仅运行已确认的内置命令；不能把 `-p /stats` 未验证地当作无推理查询 |
| [statsCommand 源码](https://github.com/google-gemini/gemini-cli/blob/main/packages/cli/src/ui/commands/statsCommand.ts) | 默认 session 路径刷新 quota；model 路径读取缓存额度 | 内部获取字段不保证最终 UI 输出可解析 |
| [ModelStatsDisplay 源码](https://github.com/google-gemini/gemini-cli/blob/main/packages/cli/src/ui/components/ModelStatsDisplay.tsx) | 没有 API 调用时直接显示无调用提示 | 新开查询会话不能假定 model 视图一定显示额度，更不能制造模型调用来绕过 |
| [StatsDisplay 源码](https://github.com/google-gemini/gemini-cli/blob/main/packages/cli/src/ui/components/StatsDisplay.tsx) | 接口声明与实际渲染字段存在差异，模型统计提示去 `/model` 查看额度 | 需要验证最终渲染链；源码里有 quota 字段不足以证明可行 |
| [CLI FAQ](https://geminicli.com/docs/resources/faq/) | 明确反对第三方取得或借用 CLI OAuth 认证直接访问后端 | AI Token Meter 不提取 OAuth token、不复制 CLI 内部私有请求；原生 CLI 自动化路径仍需按实际版本验证 |
| [会话管理](https://geminicli.com/docs/cli/session-management/) | 本机项目会话保存 tokens，文件也含提示词、回答及工具记录 | 只聚合所需计量元数据，不存储/展示正文；历史保留策略使覆盖范围不完整 |
| [API 限流](https://ai.google.dev/gemini-api/docs/rate-limits) | 限流按项目而非 Key；有不同模型/时间窗口，实际额度可在 AI Studio 查看 | API 速率上限不是月度订阅余量；Key 不能据此被当作全项目监控授权 |
| [API UsageMetadata](https://ai.google.dev/api/generate-content#UsageMetadata) | 内容响应包含该请求的 token 使用信息 | 不能由单次响应推断账户历史总量，不为计量额外生成内容 |
| [Gemini Apps 额度](https://support.google.com/gemini/answer/16275805?hl=en) | 当前说明按计算量衡量，包含五小时和每周限制 | 不能沿用旧固定每日提示次数，不能把 CLI 额度标成网页订阅额度 |

本轮未证明：公开的个人网页额度读取 API、仅凭 API Key 获取完整项目余额、无推理且无人值守的 CLI 额度读取链。未找到不等于永久不存在；必须保留这些证据边界。

## 采集与状态设计

首个实施检查点是版本化能力探测：核对官方 CLI 内置 `/stats`、`/model` 的可见输出、启动条件、退出及超时行为。用隔离 HOME、假凭据和受控传输/模拟输出证明不发送模型请求、不加载用户项目工具、不自动信任、不安装扩展、不使用付费回退。真实账号检查仍需另有授权，本轮未执行。若此检查点失败，保留本机活动与官方查看入口，回传额度采集受限；不能把“完整自动额度接入”标为完成。

数据流为官方 CLI 输出 → 版本化解析器 → Gemini 快照 → 既有刷新/缓存状态 → 浮动按钮、详情、Settings。使用既有取消、超时、刷新退避和进程清理；轮询失败不覆盖最后成功样本的时间戳。不新增私有后端 OAuth 客户端。

额度必须同时具备来源、适用模型/池、剩余或已用值及总量/明确百分比才绘制进度。统一浮动环为“已用”，仅在同一池内换算；不同模型池不相加，优先官方共享池，否则展示受限最明显的有效池并在详情明确其名称。未知上限或时间显示“暂无法获取”，不能填 0 或计算假重置时间。已知耗尽可显示已用 100%，错误与耗尽分开。

本机活动以单独摘要保存：设备范围、可用日期范围、模型及输入/输出/缓存/thinking tokens，按上游字段语义处理，避免把 total 与分项重复相加。以会话/消息稳定标识去重，处理重写、删除、部分 JSON、权限与过大文件。不同认证/账户归属不能证明时标为“本机 Gemini CLI 活动”，不归到当前账号，也不进入官方额度环。请求数与 token 数不能互换；没有记录显示“无可用记录”，不能断言账号从未使用。

| 可观测状态 | 用户所见/动作 |
| --- | --- |
| 明确未找到 CLI | 未安装 Gemini CLI；提供官方安装引导，用户点击才执行 |
| 已安装但要求认证 | 需要登录；提供官方 CLI 登录入口 |
| 认证过期 | 登录已失效；重新登录，保留旧样本的过期标记 |
| CLI 认证为 API/Vertex | 明确显示该模式；首期不承诺订阅额度，不要求重复登录掩盖能力不足 |
| 已登录但额度缺字段/版本不支持 | 暂无法获取额度；本机活动仍可独立展示，提供官方查看方式 |
| 权限、网络、路径或解析错误 | 准确错误和重试动作，不能误报未安装/未登录 |
| 有有效额度 | 官方 CLI 额度、适用范围、更新时间及实际重置时间 |

Gemini 品牌按钮名可为 Gemini，详情数据标题必须为 Gemini CLI。安装 Gemini 桌面应用不等于安装 CLI。扩展既有状态模型和共享合同，保持三处状态同源；更全面的新用户发现/恢复审计属于后续015。

## 四按钮与设置

保留深海背景、现有三个品牌配色及 Logo-only 排列。Gemini 使用可核对来源的四角星品牌资产，新增环强调色青绿（推荐）或玫红；配色提案不声称是 Google 官方品牌规范。实现前核对资产来源与可用条件。小尺寸通过图形、可访问名称和文字详情辨识，不能仅靠颜色区分。

纵向四个按钮保持现有宽度、圆环尺寸和间距，只增加一行高度。左右贴边不改变上下顺序，不镜像 Logo，不恢复刚移除的顶部横线。
