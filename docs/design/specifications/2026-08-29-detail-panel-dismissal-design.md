# AI-Meter 详情浮层自动收起设计

日期：2026-08-29

## 目标

让右侧悬浮仪表的详情窗成为临时浮层，而不是持续占据桌面。详情窗默认显示 8 秒，支持在设置中选择显示时长，并在用户点击浮层之外时立即收起。

## 用户行为

- 点击任一服务圆环会打开对应详情窗，并从头开始自动隐藏倒计时。
- 默认自动隐藏时间为 8 秒；设置提供 3、5、8、15、30 秒五个固定选项。
- 切换到另一个服务圆环会立即更新详情，并重新开始完整倒计时。
- 再次点击当前圆环会立即关闭详情窗。
- 点击详情窗内部或悬浮条内部不会因“外部点击”而关闭；圆环自身的切换行为仍按上述规则执行。
- 点击菜单栏、AI-Meter 设置窗口、其他应用或桌面空白处会立即关闭详情窗。
- 关闭整个右侧悬浮仪表时，详情窗同时关闭。
- 自动隐藏或外部点击关闭后，圆环选中状态同步清空；下一次点击同一圆环必须立即重新打开详情。
- 修改时长设置后，新时长从下一次打开或切换详情时生效。由于点击设置窗口本身会关闭当前详情，不需要在正在显示的详情上重排计时。

## 架构

### 共享选择状态

新增一个仅负责悬浮窗交互状态的可观察对象，由 `FloatingPanelController` 持有，并传入 `FloatingStripView`。它只保存当前选中的 `UsageProvider?`。

SwiftUI 圆环和 AppKit 详情面板共同使用这一个状态。控制器因超时、外部点击或隐藏悬浮条而关闭详情时，必须先把选中项设为 `nil`，再隐藏面板，避免视图与窗口状态分叉。

### 自动隐藏计时

`FloatingPanelController` 持有一个可取消的异步任务：

1. 打开详情或切换服务时取消旧任务。
2. 从 `AppModel.detailAutoHideSeconds` 读取当前设置并启动新任务。
3. 时间到达后在主执行域确认该服务仍是当前选择，再清空选择并隐藏详情。
4. 手动关闭、外部点击、隐藏悬浮条和控制器销毁时取消任务。

对当前服务的身份检查可以防止旧计时器在用户已经切换服务后误关新详情。

### 外部点击监听

控制器安装两类 AppKit 鼠标监听：

- 本地监听覆盖 AI-Meter 自身的菜单、设置和窗口点击。
- 全局监听覆盖其他应用与桌面点击。

只观察左键和右键按下事件。事件发生时读取当前鼠标屏幕坐标：若坐标位于详情面板或悬浮条边界内，则保留详情；否则立即收起。监听不拦截、不修改事件，不记录坐标或点击内容，也不监听键盘。

如果系统无法建立全局监听，自动隐藏仍然工作；本应用内部点击仍由本地监听处理。该降级不会影响应用启动或其他用量采集。

### 设置持久化

`AppModel` 新增 `detailAutoHideSeconds`，使用 `UserDefaults` 持久化：

- 首次运行或旧版本升级时默认 8 秒。
- 设置页在 Appearance 区域增加“Detail auto-hide”选择器。
- 选择器只允许 3、5、8、15、30 秒，避免自由输入造成零值、负数或异常长时间。
- 读取到不受支持的历史值时回退到 8 秒。

## 生命周期与清理

- `FloatingPanelController.hide()` 同时关闭详情、清空选择并取消倒计时。
- 鼠标监听 token 和屏幕变化 observer 在控制器销毁时移除。
- 详情未显示时，点击监听快速返回，不改变其他窗口行为。
- App 退出时不保存当前选择或剩余倒计时；下次启动详情保持关闭。

## 测试与验收

### 自动化测试

- 默认值为 8 秒。
- 五个合法选项能保存和恢复。
- 不支持的持久化值回退到 8 秒。
- 打开、切换、再次点击当前服务产生正确选择状态。
- 超时只关闭启动该计时器时对应的选择，不会关闭后来切换的新详情。
- 外部点击关闭并清空选择；悬浮条或详情内部点击不关闭。
- 隐藏悬浮条会关闭详情并取消计时。

### 本机界面验收

1. 点击 Claude、Codex、DeepSeek，确认详情内容正确切换且每次重新计时。
2. 使用默认 8 秒，确认详情自动收起且圆环取消选中。
3. 把设置改为 3 秒，再次打开并确认约 3 秒收起。
4. 分别点击详情内部、悬浮条空白、AI-Meter 设置、其他应用和桌面，核对保留或收起行为。
5. 自动收起后再次点击同一圆环，确认第一次点击即可打开。

## 范围外事项

- 不增加“永不隐藏”选项。
- 不增加鼠标悬停暂停、倒计时动画或声音。
- 不改变菜单栏面板、刷新周期、通知逻辑或三个服务的数据采集。
- 不记录或分析用户点击内容。
