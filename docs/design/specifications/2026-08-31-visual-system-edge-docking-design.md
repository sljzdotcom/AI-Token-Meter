# AI Meter 视觉系统与贴边浮岛设计规格

日期：2026-08-31  
状态：已确认，待实施

## 目标

本阶段统一 AI Meter 的悬浮条、详情面板和应用图标，使产品从“黑色悬浮组件集合”升级为有明确品牌识别的原生 macOS 工具。同时消除悬浮条与屏幕右侧之间多余的空白，让它真正依附屏幕边缘，并支持用户选择左右位置或自动吸附。

确认采用的方向为：纯深色玻璃、青绿至蓝紫渐变、无图片背景、反向半圆无缝贴边、无文字仪表指针 Logo。

## 当前问题审查

### 视觉层级

- 悬浮条和三种详情页分别硬编码近黑色背景、阴影和多个白色透明度，单独可用但缺少统一系统；
- 卡片、背景和辅助文字之间的明度差较小，部分信息在深色桌面上不够清晰；
- 状态色既承担品牌识别又承担风险提示，容易让正常用量和警告状态产生视觉竞争；
- 详情页圆角、卡片圆角、间距和阴影参数相近但不一致。

### 悬浮条定位

- `FloatingPanelController` 当前把 84 点宽的窗口固定在可见屏幕右侧内缩 12 点的位置；
- SwiftUI 内容外又包含透明画布、大圆角和向左下扩散的阴影，因此视觉空白大于 12 点；
- 窗口只能固定在右侧中央，无法记住用户偏好的侧边和垂直位置。

### 品牌 Logo

- 三个用量环外径相同，内部品牌素材也使用相同的像素框，但素材留白和图形重量不同；
- Claude PNG 的透明留白和细线使它看起来偏小，DeepSeek 横向轮廓更饱满，Codex 接近基准；
- 应用当前没有独立且有辨识度的 App Icon。

## 视觉系统

### 颜色令牌

所有悬浮界面共享一个集中定义的视觉主题，避免在各个 View 内重复写透明度：

| 令牌 | 建议值 | 用途 |
| --- | --- | --- |
| `glassBase` | `#070A10` | 浮岛和详情页最深背景 |
| `glassElevated` | `#0D121D` | 详情页主表面 |
| `cardSurface` | `#171D29`，带低透明度 | 指标卡、券卡、统计卡 |
| `primaryText` | `#F2F6FE` | 标题和关键数值 |
| `secondaryText` | `#A4AEC0` | 标签和说明 |
| `tertiaryText` | `#687388` | 更新时间、来源和弱提示 |
| `mintAccent` | `#54EDC6` | 正常状态、起始渐变、交互焦点 |
| `violetAccent` | `#7769FF` | 结束渐变、品牌层次 |

警告、危险、过期和陈旧状态继续使用现有语义色，不把蓝紫品牌色用于风险提示。无障碍“增强对比度”开启时，卡片明度差和文字对比度提高；“减少透明度”开启时，用不透明深色表面替代玻璃效果。

### 表面层级

界面固定为三层：桌面背景、深色玻璃主表面、轻微提亮的内容卡。卡片通过明度与内侧高光区分，不增加明显白色描边。阴影只用于把整个详情面板或浮岛从桌面分离，内部卡片不使用大阴影。

圆角层级统一为：浮岛的主体圆弧 34–38 点、详情面板 24–26 点、内容卡 14–16 点、小胶囊使用完全圆角。间距使用 4 点网格，并以 8、12、16、20 点为主要档位。

### 背景约束

正式产品不使用抽象图片背景。青绿和蓝紫只出现在 Logo、进度环、状态重点和极弱的环境高光中，保证三个品牌图形和详情文字始终是视觉主体。

## 贴边浮岛

### 轮廓

悬浮条采用一块连续的自定义形状，而不是圆角矩形叠加独立端帽。中段容纳三个 60 点用量环；顶部和底部从屏幕边缘通过反向半圆向主体内收。该形状不显示边框线，各段之间没有接缝。

吸附右侧时，屏幕边缘位于形状右侧；吸附左侧时整个形状、阴影方向、拖动提示和详情展开方向水平镜像。浮岛窗口自身与可见屏幕边缘的间距为 0；只在桌面内侧保留阴影，不在屏幕外侧预留透明画布。

### 位置模式

新增 `FloatingStripEdgePreference`：

- `automatic`：默认设置。首次启动位于右侧；用户拖动后吸附最近的左侧或右侧，并记住最终侧边和垂直位置；
- `left`：强制吸附左侧；拖动只改变垂直位置；
- `right`：强制吸附右侧；拖动只改变垂直位置。

旧版本没有该设置时使用 `automatic + right`，保持升级后的首次位置符合现有习惯。

### 拖动交互

顶部保留短横拖动柄。拖动从拖动柄开始，三个品牌圆环继续只负责打开详情，避免点击和拖动互相抢占。自动模式中可以横向拖到另一侧；所有模式都允许调整上下位置。

拖动过程实时跟随指针；松手后以短促的弹性动画吸附到目标边缘。保存的是当前屏幕标识、最终侧边和相对于 `visibleFrame` 的归一化垂直中心值，而不是绝对坐标。

### 多显示器和屏幕变化

- 从当前浮岛所在屏幕计算可见区域；
- 拖到另一显示器后，把新显示器设为当前屏幕并保存位置；
- 显示器断开、分辨率变化、Dock 或菜单栏改变可见区域时，重新夹紧垂直位置，确保浮岛全部可见；
- 找不到已保存的显示器时回退到主屏幕和右侧中间位置；
- 全屏空间继续沿用现有 `.fullScreenAuxiliary` 行为。

### 详情面板展开

详情面板始终从浮岛朝桌面内部展开：浮岛在右侧时详情位于左边，浮岛在左侧时详情位于右边。两者保持 8–10 点视觉间隔；详情高度继续按现有 Codex 券数量和 DeepSeek 内容规则自适应，并被当前屏幕可见高度夹紧。

外部点击关闭、自动隐藏、DeepSeek 登录聚焦以及 Claude/Codex 只读交互保持现有行为。

## Logo 系统

### App Icon

采用无文字“仪表指针”图形：

- 底板为深靛色圆角方形，带青绿至蓝紫的柔和渐变；
- 中心是分段用量环和一根清晰指针，表达 Meter 与额度监控；
- 不出现 `AI`、服务商名称或其他字母；
- 图形必须在 16、32、64、128、256、512 和 1024 点尺寸上清晰；
- 同一矢量母版生成 `.icns` 所需位图，不依赖生成式图片作为最终资产。

### 服务 Logo 光学校正

不修改 Claude、Codex、DeepSeek 原始品牌资源，只集中定义每个服务的光学缩放：

- Claude：适当放大以抵消透明留白和细线；
- Codex：作为基准尺寸；
- DeepSeek：略微缩小以平衡横向轮廓。

校正后的可见图形面积和视觉重量应接近，而不是强求源文件边界完全相等。悬浮条、菜单卡和详情页统一复用同一缩放规则。

## 设置界面

“Floating strip”区域新增屏幕边缘选项：`Automatic`、`Left`、`Right`。说明文字明确：Automatic 可拖到任一侧并记住位置；Left/Right 固定侧边但仍可上下拖动。

设置变更立即重新定位已显示的浮岛，不需要重启应用。现有显示开关和详情自动隐藏时长保持不变。

## 组件边界

- `AIMeterVisualTheme`：集中提供颜色、表面、间距、圆角和阴影令牌；
- `FloatingStripShape`：只负责左右镜像的连续浮岛轮廓；
- `FloatingStripPlacement`：纯值类型，计算侧边、归一化垂直位置和屏幕内夹紧结果；
- `FloatingStripPositionStore`：读取和持久化侧边偏好、最近吸附侧和垂直位置；
- `FloatingPanelController`：接收纯布局结果并更新 `NSPanel`，协调拖动和详情展开，不自行保存几何规则；
- `ProviderLogoStyle`：集中定义各服务的光学校正；
- SwiftUI View：消费上述规则，不直接重复硬编码颜色或绝对窗口位置。

## 错误处理与恢复

- 无效或损坏的位置偏好回退到 `automatic + right + 垂直居中`；
- 归一化垂直值在读取和保存时夹紧到 `0...1`；
- 无法识别屏幕时使用 `NSScreen.main`，仍不可用时保留当前窗口位置而不崩溃；
- App Icon 生成脚本缺少源文件或系统工具时构建失败并给出明确错误，不静默打包无图标应用；
- Logo 资源缺失时继续使用现有 SF Symbol 回退。

## 测试与验收

### 自动化测试

- 位置偏好的默认值、持久化和损坏数据回退；
- 左、右和自动模式的侧边选择；
- 归一化垂直位置到不同屏幕尺寸的换算和夹紧；
- 屏幕断开或可见区域变化后的回退；
- 左右详情面板展开方向和屏幕边界约束；
- 拖动柄与服务按钮的命中区域不冲突；
- 三个服务 Logo 均使用集中光学校正规则；
- 现有自动关闭、外部点击、DeepSeek 聚焦和无障碍测试继续通过。

### 视觉验收

- 浅色、深色和高对比度桌面下，浮岛边缘无透明空白、无端帽接缝、无可见框线；
- 左右吸附轮廓正确镜像，阴影只向桌面内部扩散；
- 三个品牌 Logo 在 60 点圆环中视觉大小接近；
- App Icon 在 Dock、Finder 列表和设置页中均可辨认，指针不会糊成一块；
- Claude、Codex、DeepSeek 详情页的背景、卡片、文字层级和间距保持一致；
- “减少透明度”和“增强对比度”模式可读。

### 发布验收

完整 Swift 测试、Release 构建、Info.plist、签名、arm64 架构、App Icon 打包、安装版哈希以及真实启动检查全部通过后，才允许合入 `main`。

## 非目标

- 不改变三家服务的数据采集、额度计算或刷新频率；
- 不增加背景图片或动态壁纸；
- 不重新绘制服务商品牌 Logo；
- 不改变详情面板的业务内容；
- 不增加常驻动画，避免耗电和视觉干扰。
