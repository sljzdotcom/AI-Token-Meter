# 浮动条镜像轮廓与底部入口移除规格

关联需求：REQ-20260911-006、REQ-20260911-007、REQ-20260911-008。日期：2026-09-11。

## 最终决定

用户确认收起态使用14pt可见宽度，并在连续预览验收后取消全部底部Settings提示弧和齿轮。展开态只保留服务圆环与深海背景；静止、主体悬停、键盘焦点均不在浮动条底部显示设置入口。Settings继续通过应用既有菜单和设置窗口入口打开。

## 收起态

- 原生透明命中窗口为20×96pt/px，继续贴紧屏幕左右边缘并保持展开态的垂直中心。
- 可见把手为14×88pt/px，在命中窗口内垂直居中并贴紧屏幕边缘。
- 把手上下使用严格镜像的内凹曲线；右侧贴边基准路径为 `(14,0) → (6.3,18) → (0,30) → (0,58) → (6.3,70) → (14,88)`，左侧只做水平镜像。
- 深海背景与中央2pt×28pt弱高光保留；不恢复7pt胶囊圆角矩形。

## 展开态

- 窗口高度等于内容高度，不再追加42/48pt Settings区。Mini/Compact的1–4服务高度为170/228/286/344pt/px；Comfortable为212/284/356/428pt/px。
- Mini宽65、Compact宽78、Comfortable宽108保持不变；圆环、间距、Logo、排序与点击行为保持不变。
- 下肩严格垂直镜像上肩。Mini四服务右侧路径依次通过 `(65,8)`、`(42,22)`、`(0,70)`、`(0,274)`、`(42,322)`、`(65,336)`，最终沿屏幕边缘闭合；Compact和Comfortable使用各自上肩控制点的垂直镜像。
- 四服务Mini/Compact圆环中心继续为85/143/201/259pt/px，首尾圆环外接矩形到窗口上下各留61pt/px。

## 交互与无障碍

- 移除底部弧线、Settings按钮、独立悬停状态、命中区和辅助功能节点；悬停只维持原有展开/收起状态机。
- Provider按钮、背景拖动、右键菜单、详情面板、自动收起设置及应用原有Settings入口不变。
- 双平台必须在左右贴边、1–4服务和所有密度下保持轮廓镜像、圆环完整包含、空白背景可拖动、Provider仅点击。

## 发布边界

本规格只授权实现、测试、审查和形成可评审候选；0.8.0的发布授权不自动延伸到下一版本。新版本发布需单独授权。
