# Windows 语言与字体规格

需求：REQ-20260907-002、REQ-20260907-003。用户授权按推荐实施；macOS 不增加语言设置或改变字号。

## 语言

Appearance 新增 English / 简体中文，默认 English，保存并即时通知全部应用窗口及原生菜单。应用自有 Settings、详情、状态、托盘/右键菜单、通知、错误和无障碍标签均翻译；服务名不变。数字日期按界面语言格式化，不将显示文本作为业务协议。未知/缺失语言回退 English。CLI、官网和操作系统第三方页面不强行翻译。

## 字体

保留原字体选项，新增 Microsoft YaHei（微软雅黑）、SimHei（黑体）、KaiTi（楷体）。新安装与恢复默认使用 Microsoft YaHei；升级保留用户已保存的选择。仅使用本机字体，缺失时标记不可用并回退微软雅黑/系统 sans-serif，不下载或打包商业字体。

Settings 所有区域始终用默认系统字体及原有字号，选择项只显示字体名；选择影响浮动条、详情及应用内容面板。原生菜单跟随系统。

## 详情字号追加要求

以当前 Windows 详情的每项 CSS 字号为基线，各减少 1 CSS px：标题、摘要数值、正文、按钮、图表标签、辅助文案、空/错误状态；不通过 zoom/整体缩放实现。不改变 Settings、浮动条、托盘菜单字号。保持自适应高度/滚动及图表可读性。

## 验证

测试偏好迁移、非法值回退、保存与事件传播、全量翻译键对齐、原生菜单更新、字体缺失回退；用真实 DOM/浏览器计算样式对比全部详情字号，验证 Settings 隔离。运行 Windows 前端、Rust、严格 lint、生产构建；Windows-only API 由 Windows CI 验证，真机中文/不同 DPI 单独记录。
