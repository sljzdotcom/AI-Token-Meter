# AI Meter 浮岛紧凑短肩规格

日期：2026-08-31  
状态：已确认，待实施

## 背景

当前贴边浮岛使用三段连续 S 曲线。顶部从屏幕边缘 `(108, 0)` 展开到主体直边 `(0, 104)`，底部严格镜像。虽然连接已经连续且没有外投影，但每个肩部的垂直展开达到 104 点，在窄浮岛上显得外鼓范围过大。

用户在实际安装版截图上用红线标注了目标轮廓，并从三种视觉对比中选择方案 A：**紧凑短肩**。目标形态是靠近屏幕边缘的短平台，加一段紧凑圆弧进入中央主体，而不是继续使用长 S 曲线。

## 目标

- 把上下肩部从长 S 曲线改成短平台与紧凑圆弧；
- 将顶部进入主体直边的位置从 `y = 104` 收到 `y = 88`，底部严格镜像；
- 保持中央主体、三个圆环、窗口、详情和交互尺寸不变；
- 左右贴边继续共享同一条基准路径并水平镜像；
- 不恢复外投影、描边、背景图片或额外装饰；
- 在实际安装版中确认浅色和复杂壁纸上不再出现过大的肩部外鼓。

## 精确轮廓

基准画布保持 `108 × 356` 点，右贴边基准路径使用以下坐标：

1. 顶部贴边起点：`(108, 16)`；
2. 短平台终点：`(66, 28)`，控制点 `(98, 23)`、`(88, 27)`；
3. 紧凑圆弧终点：`(0, 88)`，控制点 `(29, 29)`、`(0, 54)`；
4. 中央直边：从 `(0, 88)` 到 `(0, 268)`；
5. 底部圆弧终点：`(66, 328)`，控制点 `(0, 302)`、`(29, 327)`；
6. 底部贴边终点：`(108, 340)`，控制点 `(88, 329)`、`(98, 333)`；
7. 关闭路径，沿屏幕边缘连接 `(108, 340)` 与 `(108, 16)`。

上下坐标严格关于 `y = 178` 镜像。左贴边继续由相同坐标在 `x = 54` 两侧水平镜像，不维护第二套路径。

与当前路径相比，新路径取消三个阶段的长 S 展开，把顶部主体接入点由 `(0, 104)` 调整为 `(0, 88)`，同时让边缘附近先形成接近水平的短平台，再用单段圆弧进入直边。

## 布局与交互约束

- 浮岛窗口仍为 `108 × 356`；
- 三个圆环的大小、中心位置、间距和 Logo 光学校正不变；
- `FloatingStripDragShape` 继续使用可见轮廓，并排除三个 Logo 点击区域；
- 新轮廓外的透明肩部不得开始拖动；
- 圆环之间与主体空白区域仍可拖动；
- Automatic、Left、Right、多显示器、位置持久化和详情展开方向不变；
- Claude、Codex、DeepSeek 的当前配色和数据逻辑不变。

## 测试与验收

按测试驱动顺序实施：

1. 先增加方案 A 的路径边界和内外采样测试，并在旧路径上确认失败；
2. 校验顶部和底部关于 `y = 178` 对称，左右贴边严格镜像；
3. 更新真实拖动区域测试，确保透明区不响应、玻璃主体仍响应；
4. 运行视觉、拖动、指针、布局和完整测试；
5. 构建 Release，验证签名和安装包；
6. 安全备份旧安装版并安装新版本；
7. 在实际桌面上验收右贴边和左贴边轮廓、拖动、Logo 点击及 Settings；
8. 验收通过后记录测试、构建、安装与 Git 版本信息。

- 不修改服务配色、额度算法、采集、缓存、凭证或刷新逻辑；
- 不增加用户可调曲率选项；
- 不修改详情页视觉；
- 不恢复黑色外阴影。
