# AI Meter 设计规格

- 状态：暂定版，已获用户确认
- 日期：2026-08-28
- 平台：macOS 14 及以上
- 项目目录：`/Volumes/DockData/Cloud/Dropbox/Documents/Develope/AI Project/AI-Meter`

## 1. 目标

构建一个完全在用户 Mac 上运行的原生菜单栏 App，统一显示 Claude、Codex 与 DeepSeek 的用量状态。Claude 与 Codex 展示订阅额度、已用比例和重置时间；DeepSeek 展示 API 余额、本月预算消耗和可用状态。App 在达到 70% 与 90% 阈值时发送 macOS 本地通知。

成功标准：用户无需分别打开三个客户端或网页，即可在菜单栏或右侧悬浮条中看到三项最新用量；数据来源与各自 CLI/API 的显示一致；凭证不离开本机安全存储。

## 2. 第一版范围

### 包含

- 原生 SwiftUI 菜单栏 App。
- 可选的屏幕右侧悬浮用量条。
- Claude Code CLI `/usage` 用量读取。
- Codex CLI `/status` 用量读取。
- DeepSeek 官方余额接口读取。
- 5 分钟自动刷新与手动刷新。
- 70% 和 90% 两级 macOS 本地通知。
- 缓存最后一次成功结果并显示更新时间。
- 登录状态、网络异常、解析失败和超时状态提示。
- 登录时自动启动选项。
- 浅色与深色外观。

### 不包含

- Windows 或 Linux 客户端。
- Claude、Codex 或 DeepSeek 的聊天功能。
- 代替用户登录账号或创建账号。
- 浏览器 Cookie 抓取。
- 上传用量到云端、团队共享或远程仪表盘。
- 自动购买额度、充值或变更套餐。
- 除 Claude、Codex、DeepSeek 之外的提供商。

## 3. 用户体验

### 菜单栏

菜单栏图标显示三项服务中最高的已用比例所对应的状态颜色。点击图标打开详情面板；面板按 Claude、Codex、DeepSeek 顺序展示摘要，用户可点击任一服务查看完整指标、重置时间、连接状态与最后更新时间。

### 右侧悬浮条

悬浮条沿屏幕右侧显示三个细圆环，与确认的参考视觉一致：黑色有机轮廓、克制的阴影、细轨道和高对比数字。点击圆环展开黑色详情卡片。悬浮条默认开启，可在设置中关闭；关闭后菜单栏功能保持完整。

### 指标

- Claude：当前会话/滚动窗口已用比例，以及所有模型或周额度已用比例和重置时间。
- Codex：CLI `/status` 返回的短周期额度、周额度或当前账户实际提供的指标和重置时间。
- DeepSeek：官方余额、可用状态，以及相对于本地“月度预算”的消耗比例。月度预算默认 100 CNY，用户可在设置中修改。余额不充当预算上限。

### 设置

- 是否显示右侧悬浮条。
- 是否登录时自动启动。
- 自动刷新间隔：固定为 5 分钟；第一版不提供更短间隔。
- 是否启用 70% 与 90% 通知。
- DeepSeek 月度预算，默认 100 CNY。
- DeepSeek API Key 的新增、替换与移除。

## 4. 架构

App 按职责拆分为六个边界清晰的模块：

1. `AppShell`：生命周期、菜单栏入口、设置窗口与自动启动。
2. `Collectors`：Claude、Codex、DeepSeek 三个独立采集器。
3. `Domain`：统一用量模型、刷新协调与状态计算。
4. `Storage`：非敏感偏好与缓存；敏感凭证使用 Keychain。
5. `Notifications`：阈值判断、去重与重置周期管理。
6. `UI`：菜单栏面板、悬浮条、详情卡片与错误状态。

各采集器实现同一接口，返回统一的 `UsageSnapshot`。UI 与通知模块只依赖该领域模型，不依赖 CLI 文本或 DeepSeek JSON 的具体结构。

### 4.1 领域模型

`UsageSnapshot` 至少包含：

- `provider`
- `primaryMetric`
- `secondaryMetric`
- `availability`
- `fetchedAt`
- `staleAfter`
- `sourceVersion`
- `collectionStatus`

每个指标包含显示名称、当前值、单位、上限、已用比例和可选的重置时间。缺少上限时不伪造百分比，只显示官方返回的绝对值。

### 4.2 ClaudeCollector

- 发现用户现有的 `claude` 可执行文件。
- 通过受控伪终端启动 Claude Code，并仅发送固定的 `/usage` 指令。
- 解析计划用量条、比例和重置时间。
- 不读取、导出或复用 Claude OAuth 令牌。
- 采集完成后正常退出；如果 CLI 对重复启动产生明显开销，改为复用单个受控后台会话，但对外接口不变。
- 单次采集最多等待 10 秒。

### 4.3 CodexCollector

- 发现用户现有的 `codex` 可执行文件。
- 通过受控伪终端启动 Codex CLI，并仅发送固定的 `/status` 指令。
- 解析订阅额度、比例、余额和重置时间。
- 不读取或导出 Codex 登录令牌。
- 单次采集最多等待 10 秒。

### 4.4 DeepSeekCollector

- 从 macOS Keychain 读取 API Key。
- 调用 DeepSeek 官方 `/user/balance` 接口。
- 解析币种、总余额、赠送余额、充值余额与可用状态。
- 根据用户配置的月度预算计算本地预算消耗比例；明确标注该比例是本地预算指标，不是 DeepSeek 官方订阅额度。
- 单次请求最多等待 10 秒。

### 4.5 RefreshCoordinator

- App 启动后立即触发一次全量刷新，目标是在 10 秒内显示第一批结果。
- 此后每 5 分钟刷新一次。
- 三个采集器并发运行，任一失败不阻塞其他服务。
- 手动刷新沿用同一流程，并防止重复并发刷新。
- Mac 睡眠时不刷新，唤醒后补充刷新一次。

## 5. 数据流

1. `RefreshCoordinator` 发起刷新。
2. 三个采集器独立获取原始结果。
3. 解析器将结果转换为 `UsageSnapshot`。
4. 有效结果写入本地缓存并发布给 UI。
5. `NotificationEvaluator` 比较新旧快照和当前额度周期。
6. 达到阈值时发送本地通知，并记录该周期已发送的级别。
7. 额度周期重置后，阈值记录自动清除。

## 6. 本地存储与安全

- DeepSeek API Key 只存入 macOS Keychain。
- UserDefaults 只保存显示偏好、预算、通知开关、上次通知状态和非敏感缓存索引。
- 快照缓存不保存聊天正文、提示词、代码、OAuth 令牌或 API Key。
- App 只允许执行预定义的 Claude/Codex 状态查询，不接受用户输入作为 shell 命令。
- CLI 子进程使用固定参数、受限环境和明确超时。
- 日志默认不记录 CLI 原始输出；诊断日志仅记录采集阶段、状态码、CLI 版本和去敏错误类别。
- App 不向自建服务器或第三方分析服务上传数据。

## 7. 异常处理

- CLI 未安装：显示“未安装”，提供可执行路径检测结果，不影响其他服务。
- CLI 未登录：显示“需要登录”，不尝试绕过或复用凭证。
- CLI 输出无法解析：保留上次成功快照并标记“数据可能已过期”。
- 网络中断或 DeepSeek 失败：显示缓存值、最后更新时间和离线状态。
- API Key 无效：显示“鉴权失败”，不在界面或日志中展示 Key。
- 子进程卡住：10 秒后终止该次采集并记录超时。
- 单个采集器崩溃：隔离失败并继续更新其他服务。
- 连续失败：不重复发送错误通知，只在界面中维持明确状态。

## 8. 通知策略

- 每个提供商、每个额度周期的 70% 与 90% 阈值各通知一次。
- 一次刷新跨越两个阈值时只发送最高级别通知。
- 额度周期重置或已用比例显著回落到 10% 以下时，开启新周期。
- DeepSeek 使用本地月度预算周期；余额不可用时不触发预算通知。
- 通知点击后打开对应服务的详情面板。

## 9. 测试设计

### 单元测试

- Claude 与 Codex 解析器：中英文输出、不同套餐、缺失字段、格式变化和 ANSI 控制字符。
- DeepSeek 解析器：多币种、余额不足、空余额数组和字段异常。
- 阈值逻辑：70%、90%、跨级、去重与周期重置。
- 缓存状态：新鲜、过期、无缓存与时间回拨。

### 集成测试

- 伪终端启动、固定命令发送、超时和正常退出。
- Keychain 新增、读取、替换和删除。
- DeepSeek 模拟服务器的成功、401、429、500 和超时。
- 三采集器并发时的部分失败。

### UI 与系统测试

- 菜单栏面板和悬浮条的浅色/深色快照。
- 多显示器、不同缩放比例与屏幕边缘定位。
- 登录启动、睡眠/唤醒和网络切换。
- 通知权限拒绝与通知点击跳转。
- VoiceOver 标签与键盘操作。

## 10. 验收标准

- App 启动后 10 秒内至少显示已成功连接服务的第一批数据。
- 默认每 5 分钟自动刷新，手动刷新可立即触发。
- 三项指标与各自 CLI/API 在同一时刻的显示一致。
- 断网、未登录、CLI 升级和子进程超时时 App 不崩溃。
- 70% 与 90% 通知按周期正确触发且不重复。
- DeepSeek API Key 不出现在配置文件、缓存、日志或 Git 历史中。
- 悬浮条可关闭，菜单栏功能始终可用。
- 空闲时不持续运行模型请求，不产生聊天或推理调用。
- macOS 重启后可按用户设置自动启动，并恢复显示与通知偏好。
