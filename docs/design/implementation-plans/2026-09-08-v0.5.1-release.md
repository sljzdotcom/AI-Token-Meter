# 0.5.1 Windows 修复稳定发布计划

关联 REQ-20260908-006。用户明确授权直接发布以便 Windows 应用内更新；依照既定双平台合同，共同发布 0.5.1/macOS build14，macOS 不改产品行为。

本轮仅顺序执行现有发布操作，无新功能开发。发布脚本要求干净 main，沿用已批准的 main 发布入口，不创建新的功能工作树或改变签名信任根。

1. 同步根、两端元数据及版本测试；保留依赖版本和历史负例，补 Release Notes、CHANGELOG、索引与日志。发布前不声称已上架。
2. 验证文档、合同、公开安全、聚焦元数据和 Windows 前端；提交版本准备。
3. 用现有 `package-cross-platform-release.sh 0.5.1 14` 完整测试、构建并用 Keychain 签 macOS 资产；创建新 tag/草稿，运行既有双平台 release.yml。不导出私钥，不替换旧版资产。
4. 等待标签测试、Windows 签名 NSIS、验签及公开流程成功；使用本版 Release Notes。失败遵循既有恢复流程，不绕过测试。
5. 匿名下载公开安装器和两个 Windows 更新入口，核对更高版本、URL、SHA-256、原公钥签名；同步验证 macOS 公开 ZIP/appcast。完成台账与当前版本文档，不自动安装维护机器或操作账号。

真实 Windows 用户额度、初始化与物理设备验收继续归 REQ-20260908-001，不因发布自动完成。执行证据见[发布日志](../../development/2026-09-08-v0.5.1-release.md)。
