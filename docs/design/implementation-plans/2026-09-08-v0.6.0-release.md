# AI Token Meter 0.6.0 稳定发布实现计划

> **面向 AI 代理的工作者：** 在长期开发对话内顺序执行；每个检查点以独立审查与新鲜验证证据放行。步骤使用复选框跟踪。

**目标：** 将 Gemini 第四 Provider 与当前累计未发布改动安全交付为双平台稳定版 0.6.0（macOS build 15），并验证现有设备使用的更新通道。

**架构：** 先在功能分支准备版本和用户文档，通过本地全套与 pull request 的原生 Windows/macOS 门禁；随后合入 `main`，从干净主分支用既有 Sparkle Keychain 和 Tauri Actions Secret 生成同一标签的双平台资产。发布 workflow 只有在标签复验、原生 Windows 测试、签名安装器和恢复保护全部通过后才公开 Release 并推进三条更新入口。

**技术栈：** Swift 6/SwiftPM、Tauri 2、Rust 1.88、React/Vitest、GitHub Actions、Sparkle 2.9.4、Tauri minisign、NSIS。
