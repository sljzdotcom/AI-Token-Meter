# v0.10.8 Antigravity共享额度发布计划

**需求：** REQ-20261009-003。将已完成的 Antigravity Claude/GPT 共享额度详情作为 v0.10.8/build36 双平台稳定版发布。

**范围：** 包含双平台共享额度详情、必要合同/回归测试、版本元数据、发布说明与验证文档。沿用 [`Antigravity共享模型额度规格`](../specifications/2026-10-09-antigravity-shared-model-quota-design.md) 和既有签名发布流程。自动刷新暂停逻辑保持不变，暂停状态尽力持久化；不得声称一次性额度读取或本次发布恢复了周期刷新。

## 执行步骤

1. 从最新 `origin/main` 的获准候选分支更新所有双平台版本元数据至 0.10.8，macOS build 更新为 36；更新版本合同测试、CHANGELOG、候选说明和发布记录索引。
2. 执行 `scripts/test.sh`、Windows 前端与 Rust 测试/格式/Clippy、跨平台合同、安全与 `scripts/check-docs.sh`；检查差异与版本一致性，完成独立发布审查。
3. 将候选分支推送并创建针对 `main` 的 PR；等待 macOS 与 Windows CI 完成，处理其报告的阻塞，确认最终 diff 仅包含获准范围。
4. 在通过检查后按用户明确授权合并 PR；在合并后的 `main` 精确提交创建 `v0.10.8` 标签与草稿 Release，触发现有 `release.yml` 完成原生 Windows 签名验证与打包。
5. 仅在双平台工作流成功后公开 Release。匿名下载验证 macOS 与 Windows 资产、SHA-256、签名和三个更新入口；补全发布记录并回传协调入口。

## 安全边界

- 不强制更新远端分支、不覆盖 tag 或历史发布，不删除 Release。
- 不导出或上传私钥，不使用真实 Google 账号、CLI 会话或浏览器授权，不安装到用户设备。
- Windows 本机非原生验证不替代 Windows CI；发布需等待 `windows-latest` 检查通过。
