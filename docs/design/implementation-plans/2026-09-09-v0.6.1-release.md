# AI Token Meter 0.6.1 稳定发布实现计划

> **面向 AI 代理的工作者：** 在长期开发对话内顺序执行；每个检查点以独立审查与新鲜验证证据放行。步骤使用复选框跟踪。

**目标：** 将四服务商新用户接入一致性与 Gemini 安装引导修复交付为双平台稳定版 0.6.1（macOS build 16），并验证现有安装使用的三条更新入口。

**架构：** 先在发布分支同步版本、测试合同和用户文档，通过本地全套与 pull request 的原生 macOS/Windows 门禁；随后合入 `main`，从干净主分支使用既有 Sparkle Keychain 与 Tauri Actions Secret 生成同一标签的双平台资产。发布 workflow 只有在标签复验、原生 Windows 测试、签名安装器与恢复保护全部通过后才公开 Release 并推进稳定更新源。

**技术栈：** Swift 6/SwiftPM、Tauri 2、Rust 1.88、React/Vitest、GitHub Actions、Sparkle 2.9.4、Tauri minisign、NSIS。
