# Antigravity 安全自动刷新恢复计划

**需求：** REQ-20261009-001
**规格：** [安全自动刷新恢复规格](../specifications/2026-10-09-antigravity-safe-auto-refresh-design.md)

1. 添加协调器回归测试：一次检查成功可恢复，失败保持暂停；确认重启与非 Gemini cache isolation；验证授权单次消费、取消及暂停状态写入失败。
2. 添加 AppModel 回归测试：仅有效单次额度结果解除暂停，并展示已恢复；登录失败、查询失败、过期回执、重复开始和取消继续 fail closed。
3. 实现由登录成功回执签发的一次性授权、额度快照与暂停状态的提交边界，写盘失败回滚缓存；AppModel 同步更新暂停状态和界面。
4. 更新中英文、简体/繁体提示，使用户知晓需完成官方登录并通过一次检查才会恢复自动刷新。
5. 新增开发记录、验证记录和本地提交；不发布。
6. 运行相关测试、完整 Swift 测试、文档/合同门禁、构建和独立代码审查；从 `docs/requirements-backlog.md` 重新检查待办状态。
