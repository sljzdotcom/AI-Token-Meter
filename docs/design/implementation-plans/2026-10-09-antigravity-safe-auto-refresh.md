# Antigravity 安全恢复边界实现计划

**需求：** REQ-20261009-001
**规格：** [安全恢复边界规格](../specifications/2026-10-09-antigravity-safe-auto-refresh-design.md)

当前计划只纠正候选实现的安全过度承诺。它不会完成自动周期恢复；该能力待CLI及操作系统边界得到证据后另行设计。

1. 将回归断言改为：一次成功恢复读取写入缓存后仍保留暂停，协调器重建后不启动普通collector。
2. 将AppModel的成功态断言改为：quota快照与时间更新，但paused/action-needed状态不清除。
3. 删除Coordinator/AppModel对成功单次读取清除暂停状态的行为及仅服务于清暂停事务的错误分支。
4. 将中、英、繁体中文提示改为“额度已更新，自动刷新仍保持暂停”。
5. 更新规格与开发记录，记录官方资料边界、CLI1.3.1覆盖范围、额外CLI命令、重试/去重与暂停持久化限制。
6. 运行定向App/Core回归、完整适用测试、文档检查；请求独立审查。不得运行真实`agy`、账户/Keychain、浏览器/Terminal、M4 Max或Windows现场测试；不发布。

**完成条件：** 本地单次读取失败保持暂停的自动化证据完整、复审已完成；自动周期恢复保持受环境限制，不能标记为已完成。
