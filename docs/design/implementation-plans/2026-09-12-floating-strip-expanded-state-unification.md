# 悬浮条自动隐藏展开终态统一实施计划

**目标：** 修复自动隐藏悬停展开后轮廓变尖，以及 Mini 设置需要收起/重展才可见的问题，让所有展开入口落到同一圆润终态。

**方法：** 先用可见窗口与状态机回归证明直接展开和动画展开终态不一致，再统一 macOS 最终 frame/布局提交；以合同测试核对 Windows 是否存在同类问题，只修改有失败证据的平台。

## 任务 1：补足失败回归

- [x] 扩展 macOS 屏幕测试，覆盖可见面板、自动隐藏收起→展开、三密度和即时切到 Mini。
- [x] 对比常驻展开与自动隐藏展开后的 frame、内容 bounds 和渲染轮廓合同，保留可识别拉伸路径的失败证据。
- [x] 扩展 Windows 折叠/展开合同，观察原生逻辑尺寸、前端密度与路径是否一致。
- [x] 运行专项测试并记录修复前失败。

## 任务 2：统一展开终态

- [x] 将 macOS 展开最终 frame、位置、内容布局和可见内容提交收敛为一个入口。
- [x] 移除异形窗口 frame 拉伸，展开立即无动画提交精确终态，内容淡入前再次校验并提交最新终态。
- [x] 设置变更取消旧转换并立即调用同一终态入口，确保 Mini 不依赖折叠刷新。
- [x] Windows 专项证明当前原生尺寸与前端路径一致，保持产品实现不变。
