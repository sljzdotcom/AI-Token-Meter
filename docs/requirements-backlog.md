- 状态使用：`待处理`、`进行中`、`待用户确认`、`受环境限制`、`已延期`、`已完成`。
- 完成项不删除，补充完成日期、文档和 Git 证据。
- 每个开发阶段结束后重新读取本列表，并继续处理最高优先级的可执行事项。
