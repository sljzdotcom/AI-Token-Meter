# 2026-09-09：0.6.1 四服务接入修复稳定发布

关联 `REQ-20260909-001`，交付 `REQ-20260908-015` 与 `REQ-20260909-003`。[发布计划](../design/implementation-plans/2026-09-09-v0.6.1-release.md)、[Release Notes](../releases/v0.6.1.md)。

目标为双平台稳定版 0.6.1、macOS build 16。用户已明确授权发布候选推送、原生 CI、必要修复与复审、`main` 整合、双平台签名构建、`v0.6.1` 标签、GitHub Release 和应用内稳定更新源。发布流程不代用户安装 CLI、登录真实账号、修改凭据或覆盖本机已安装应用。

## 发布范围

- Claude Code、OpenAI Codex 与 DeepSeek 详情为安装、登录、凭据和设置问题提供直达 Services 的恢复入口；带认证原因的缓存保留额度和恢复动作，普通网络缓存保持只读。
- 移除服务卡上的重复 Check Status；DeepSeek 区分首次 Save 与后续 Replace，并准确区分 API Key 余额与官网历史登录。
- Windows DeepSeek 候选 Key 验证采用完整 busy 生命周期和后端单事务保护，凭据恢复入口位于保留官网历史之前。
- Gemini 安装入口直达官方安装页，说明 Node.js 20+、固定 CLI 0.58.0 安装命令、普通 Google 登录和回流检查；认证缓存与普通缓存使用不同提示。
- 保持现有安全边界：不自动安装/登录，不删除或改写 CLI 凭据，不把真实 Key、OAuth 或 Cookie 放入 WebView、缓存、文档和日志。
