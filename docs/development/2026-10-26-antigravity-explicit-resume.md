# Antigravity 显式恢复自动刷新

关联 REQ-20261026-003。当前状态：候选实现及独立源码审查完成，原生 GREEN、合并和发布尚未完成。规格与任务见[设计](../design/specifications/2026-10-26-antigravity-explicit-resume-design.md)及[计划](../design/implementation-plans/2026-10-26-antigravity-explicit-resume.md)。

## 问题与改动

0.10.10 保留持久暂停，单次取额成功也不会恢复定时刷新。新增独立的“恢复自动刷新”动作：本次官方登录与额度检查成功、版本支持且缓存保存成功后，在五分钟内允许用户明确选择。能力仅存在内存，过期、重启、新恢复或取消后不能复用。恢复先保存状态再更新界面；保存失败保持暂停。恢复本身不执行 CLI，下一次定时刷新只调用受限额度查询。

详情和 Services 共用诊断与单个主操作，支持英语、简体和繁体中文。原有登录执行确认、清理不确定拒绝、进程期限和输出限制保留。

## 验收边界

测试使用合成账户、注入操作或假 CLI，不读取生产凭据、不清用户暂停状态、不调用真实账号。官方非交互认证行为是上游契约依赖，假 CLI 无 TTY 测试不等于任何 CLI 版本都不可能打开浏览器。初始现场服务或进程错误的根因仍未证实；产品发布和用户设备实际恢复分别记录。
