# v0.3.0-preview.3 双平台发布记录

## 背景与目标

`REQ-20260904-006` 的 Windows DeepSeek 官网历史、窗口生命周期、紧凑密度和字体下拉修复已经通过独立复审、双平台 CI 并合入 `main`，但最新公开 Preview `0.3.0-preview.2` 不包含这些代码。`REQ-20260904-008` 的目标是把精确的 `main` 修复基线发布为 `0.3.0-preview.3`（build `10`），提供同版本 macOS Apple Silicon 与 Windows 11 x64 资产，并推进 Windows 固定 Preview 更新源。

## 发布范围

- 根版本、macOS 主应用、Widget 元数据、Windows npm/Cargo/Tauri 元数据统一为 `0.3.0-preview.3`；macOS build 递增为 `10`。
- `CHANGELOG.md` 的 Windows DeepSeek 修复从 `Unreleased` 移入本版本。
- GitHub Release 同时提供 macOS ZIP、SHA-256、Sparkle Preview appcast，以及 Windows NSIS、SHA-256、Tauri minisign 和 `latest.json`。
- 固定 Windows Preview feed 更新为本版本；稳定 macOS `appcast.xml` 继续指向 `0.2.2`，Preview 不污染稳定通道。

## 安全与隐私边界

- Sparkle 私钥只从维护者 Keychain 调用，不导出、不进入 Git、日志或 Release。
- Tauri 私钥和密码只由 GitHub Actions Secrets 注入，产物用应用内置公钥复验。
- 发布前后执行公开安全扫描；Release 不包含 DeepSeek API Key、CLI 凭证、Cookie、Authorization 或个人账号响应。
- Windows 安装器仍未取得 Authenticode 发布者证书，Release Notes 保留 SmartScreen 提示；这不等同于 Tauri 更新签名。
