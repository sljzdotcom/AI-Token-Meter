- Widget 合入 `main` 的基线：`74a59ad`；后续文档提交以实际 Git 历史为准，不在此维护易过期的“当前提交”指针。
- 公共文档体系节点：`0f9852a`。
- 可移植测试入口节点：`e3381ea`。

## 维护方式

每次正式发布或完成较大的功能阶段后：

1. 从 `git log --reverse --date=short --pretty=format:'%h|%ad|%s'` 核对实际历史；
2. 在本页增加阶段摘要和关键提交；
3. 在 `CHANGELOG.md` 记录用户可见变化；
4. 在开发日志记录验证证据；
5. 不重写已发布提交含义，也不把尚未创建的 tag 写成既成事实。
