# 2026-09-08：0.6.0 Gemini 与累积改进发布

关联 `REQ-20260908-016`，并交付 `REQ-20260908-007`、`REQ-20260908-009`、`REQ-20260908-010`、`REQ-20260908-011` 与 Gemini `REQ-20260908-012`。[发布计划](../design/implementation-plans/2026-09-08-v0.6.0-release.md)、[Release Notes](../releases/v0.6.0.md)。

目标为双平台稳定版 0.6.0、macOS build 15。用户已明确授权分支推送、原生 CI、必要修复与复审、main 整合、双平台签名构建、GitHub Release 和更新源发布。发布流程不代用户登录 Gemini、消耗真实额度或覆盖本机已安装应用。

## 发布范围

- Gemini 青绿第四按钮、四服务显示排序与旧配置迁移。
- 固定官方 Gemini CLI 0.58.0 普通 Google OAuth 的模型档位额度采集；Windows 首期仅原生 CLI。
- macOS 可编辑、保存并运行时应用用量刷新间隔。
- 双平台浮动条展开态移除顶部横线。
- 双平台 Telegram 图标链接、Windows 关于页作者精简和新版深红粗体提示。

独立审查没有 Critical，并在 `46e6de7` 关闭四项 Important 与一项 Minor：GitHub Draft 现在强制使用 `docs/releases/v<version>.md`；macOS Codex 初始化从当前 App Bundle 取得客户端版本并有初始化帧回归；Gemini 登录文档改为实际提供的官方指南与重新检查；候选下载文案不再链接尚未公开的 Tag；macOS build 门禁改为只遍历语义化版本标签并比较历史最大 build，忽略固定 channel 标签。复核精确提交 `46e6de7d89d16dcfa2d0f7eafc2f70d7304ee966` 后，Critical、Important、Minor 均为 0，未发现新回归或凭据泄露。
