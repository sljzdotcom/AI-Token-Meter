# 2026-09-27：0.10.3 Codex CLI路径识别稳定发布

关联REQ-20260927-004。[发布计划](../design/implementation-plans/2026-09-27-v0.10.3-release.md)、[Release Notes](../releases/v0.10.3.md)。

用户在确认ChatGPT.app内嵌Codex CLI可运行并登录、但0.10.2无法发现后，批准最小修复并明确要求公开发布0.10.3/build31。授权覆盖候选PR、main、双平台签名资产、GitHub Release、三个更新入口和发布后匿名复验。

## 变更与本地验证

macOS定位器保留所有既有候选路径及顺序，并在其后追加用户级 `~/Applications` 与系统级 `/Applications` 中ChatGPT/Codex App的嵌套CLI位置。账户状态、额度读取和登录入口继续共用同一定位器；Windows产品行为不变，只同步版本合同。另修正Release App复制SwiftPM资源时的Contents/Resources层级。

macOS定位、账户、额度、登录和版本/更新打包相关回归共50项通过；Windows前端133项、Rust测试、格式与严格Clippy通过；6份跨平台合同、325份Markdown、发布安全检查及Windows发布feed脚本通过。0.10.3/build31 Apple Silicon Release App的资源检查、严格代码签名和Sparkle签名检查通过。独立审查无阻断项。

本机Xcode 27上，正式包装脚本在运行全量Swift测试时报告4项区域化日期/虚拟磁盘环境问题并提前停止，尚未创建tag或Release。该完整测试门禁随后在PR CI、精确main CI以及正式Release的macOS 15/Xcode 26.3预检中全部通过；未豁免测试。基于已通过的远端全量门禁，从相同合并提交完成剩余Release App打包、Sparkle签名与发布资产安全验证。
