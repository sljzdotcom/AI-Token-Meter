# 2026-09-27：0.10.3 Codex CLI路径识别稳定发布

关联REQ-20260927-004。[发布计划](../design/implementation-plans/2026-09-27-v0.10.3-release.md)、[Release Notes](../releases/v0.10.3.md)。

用户在本地诊断确认ChatGPT.app内嵌Codex CLI可运行并登录、但0.10.2无法发现后，先批准最小修复；之后明确要求“发布”，授权按双平台稳定版流程公开交付0.10.3/build31，包括候选PR、main、双平台签名资产、GitHub Release、三个更新入口和发布后验证。

## 候选范围

- macOS定位器在所有既有候选之后，追加用户级 `~/Applications/ChatGPT.app` 与系统级 `/Applications/ChatGPT.app` 中的嵌套Codex CLI路径；旧候选顺序保持。
- 账户状态、额度读取和登录入口沿用同一共享定位器；无效旧路径继续回退。
- Windows产品行为和界面保持不变，只同步0.10.3版本与安装包。

## 验证与发布事务

本地验证完成，公开事务进行中：macOS定位、账户、额度、登录及版本/更新打包相关测试分组共50项通过；Windows前端133项通过，Rust测试、格式与严格Clippy通过。6份跨平台合同、325份Markdown、发布安全检查及Windows发布feed/资产脚本均通过。macOS arm64 Release App版本0.10.3/build31构建、资源布局与严格代码签名验证通过。独立代码复审未发现阻断问题；README徽章与测试指南均为592项（571项普通测试、3项刷新调度、18项PTY runner）。

当前开发机完整Swift套件受本机macOS 27区域化日期格式和hdiutil虚拟磁盘环境影响，有既有locale预期与虚拟磁盘创建失败；相关完整门禁没有豁免，候选PR的macOS/Windows原生CI必须全绿后才合并。发布尚未完成：PR/main精确CI、签名Release、七项资产匿名重下及签名/SHA/篡改验证、三个更新入口均待记录。真实用户Mac更新后的现场额度恢复仍需该设备观察，本机CLI已登录不替代应用现场验收。
