# 2026-09-09：0.6.2 菜单面板 Logo 稳定发布

关联 `REQ-20260909-004`，交付 `REQ-20260909-002`。[发布计划](../design/implementation-plans/2026-09-09-v0.6.2-release.md)、[Release Notes](../releases/v0.6.2.md)、[功能记录](2026-09-09-menu-panel-app-logo.md)。

目标为双平台稳定版0.6.2、macOS build17。用户在得知菜单Logo已完成但仍属Unreleased后，明确要求开发直接发布新版本；授权范围包含必要代码/文档推送、PR与原生CI、main整合、标签、双平台签名资产、公开GitHub Release和三个应用内更新入口。

## 发布范围

- macOS菜单栏弹出面板在标题块左侧显示32pt现有应用图标，保持透明背景、标题/副标题对齐和右侧刷新按钮。
- Windows原生托盘菜单首行显示同一默认图标与软件名，使用禁用品牌项和原生分隔线；四服务摘要及全部事件路由保持。
- 不新增图片资产、网络请求、偏好迁移、账号字段或凭据路径；版本身份与更新公钥保持兼容。

## 版本失败先行

- Swift元数据与跨平台合同先改为期待0.6.2/build17；旧生产文件准确产生7处版本/build不符。
- Rust应用元数据测试先期待0.6.2；旧嵌入版本准确报告左值0.6.1、右值0.6.2。
- 同步根`VERSION`、主App与Widget plist、Windows npm/Cargo/Tauri及锁文件后，14项Swift定向合同和1项Rust元数据测试转绿。完整门禁与发布审查在后续章节持续记录。

## 候选与发布门禁

- 远端最高稳定标签与Release为0.6.1，0.6.2未占用；build17高于已发布build16。
- 功能交付基线：491项Swift、124项Windows前端、5项终端协议、261项Rust、真实浏览器密度和无Widget Release App已通过。0.6.2精确候选会重新运行全套，不复用旧版本证据代替发布门禁。
- 发布签名私钥不会被读取、导出、输出或写入仓库；只验证Sparkle工具/公钥和GitHub Actions Secret可用性。

## 当前阶段

版本与候选文档准备中。公开稳定版、根appcast、Windows stable及固定Preview feed在0.6.2资产公开并通过验证前继续保持0.6.1。

## 现场边界

- Windows交互式原生菜单观感、多DPI与SmartScreen仍需对应真实用户会话确认；自动化验证原生菜单项构建、Windows runner、NSIS和GUI subsystem。
- Windows仍无Authenticode；macOS仍为Apple Silicon、ad-hoc、未公证、无Widget公开包。
