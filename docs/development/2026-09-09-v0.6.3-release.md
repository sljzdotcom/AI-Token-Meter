# 2026-09-09：0.6.3 macOS About 精简稳定发布

关联 `REQ-20260909-008`，交付 `REQ-20260909-006`。[发布计划](../design/implementation-plans/2026-09-09-v0.6.3-release.md)、[Release Notes](../releases/v0.6.3.md)、[功能记录](2026-09-09-macos-about-author-line-removal.md)。

目标为双平台稳定版0.6.3、macOS build18。用户在确认macOS About作者行移除后明确回复“确认发布”；授权范围包含必要代码和文档推送、PR与原生CI、main整合、标签、双平台签名资产、公开GitHub Release和三个应用内更新入口。

## 发布范围

- macOS Settings → About移除独立的`Author: Miller`可见行，删除节点后相邻版本与三条图标链接自然靠拢。
- 版本、Twitter、GitHub、Telegram、隐私说明、更新功能、README、MIT License及代码版权归属保持。
- Windows不改About行为，只同步语义版本；应用身份、更新公钥、偏好与凭据路径保持兼容。
- `REQ-20260909-007`的Google Antigravity产品关系和额度接口尚需官方结论，不在本补丁版中猜测或改名。

## 版本失败先行

- Swift元数据与跨平台合同先改为期待0.6.3/build18；旧生产文件准确产生7处版本/build不符。
- Rust应用元数据测试先期待0.6.3；旧嵌入版本准确报告左值0.6.2、右值0.6.3。
- 同步根`VERSION`、主App与Widget plist、Windows npm/Cargo/Tauri及锁文件后，29项Swift定向合同和1项Rust元数据测试转绿。一次使用全新Swift scratch目录的复核因沙箱无法下载已固定Sparkle 2.9.4而在编译前中止；改用项目刚构建的隔离缓存后测试通过，源码与依赖版本没有因此改变。

## 候选与发布门禁

- 远端最高稳定标签与Release为0.6.2，0.6.3未占用；build18高于已发布build17。
- 功能交付基线：491项Swift、无Widget Release App、6份跨平台合同、222份文档和公开安全已通过。0.6.3精确候选会重新运行双平台全套，不复用旧版本证据代替发布门禁。
- 发布签名私钥不会被读取、导出、输出或写入仓库；只验证Sparkle工具/公钥和GitHub Actions Secret可用性。

## 当前阶段

版本与候选文档准备中。公开稳定版、根appcast、Windows stable及固定Preview feed在0.6.3资产公开并通过验证前继续保持0.6.2。

## 现场边界

- Windows交互式原生菜单、多DPI与SmartScreen仍需对应真实用户会话确认；自动化验证Windows runner、NSIS和GUI subsystem。
- Windows仍无Authenticode；macOS仍为Apple Silicon、ad-hoc、未公证、无Widget公开包。
- Gemini真实普通OAuth账号和Google Antigravity产品接入另行追踪；本次不代用户登录、安装或迁移CLI。
