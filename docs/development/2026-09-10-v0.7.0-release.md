# 2026-09-10：0.7.0 Google Antigravity 与紧凑界面稳定发布

关联`REQ-20260910-004`，交付`REQ-20260909-007`、`REQ-20260909-011`和`REQ-20260910-001`。[发布计划](../design/implementation-plans/2026-09-10-v0.7.0-release.md)、[Release Notes](../releases/v0.7.0.md)。

## 发布范围

- 第四项服务迁移为Google Antigravity，使用官方`agy -p /usage`展示Gemini与Claude/GPT四个额度窗口，并无损保留内部兼容标识、用户排序和缓存。
- Compact浮动条由78收至65pt/px，48pt/px圆环、垂直尺寸、Comfortable和折叠把手保持。
- macOS菜单面板应用Logo由32pt放大至40pt，其他布局与Windows菜单保持。
- 同期发布Windows Codex与ConPTY原生测试夹具可靠性修复；产品超时、真实协议和安全边界未降低。

- Windows交互式菜单、多DPI与SmartScreen仍需真实用户会话观察；自动化覆盖Windows runner、NSIS和GUI subsystem。

- 不代用户登录或安装Google Antigravity CLI；真实账号额度继续保留现场验收边界。
