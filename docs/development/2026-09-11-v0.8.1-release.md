# 2026-09-11：0.8.1 浮动条轮廓与设置分类稳定发布

关联`REQ-20260911-010`，交付`REQ-20260911-006`至`REQ-20260911-009`。[发布计划](../design/implementation-plans/2026-09-11-v0.8.1-release.md)、[Release Notes](../releases/v0.8.1.md)。

目标为双平台稳定版0.8.1、macOS build24。用户明确要求发布最新版本，授权覆盖必要提交、推送、PR、main合并、标签、GitHub Release和应用内更新源。

## 候选范围

- 收起态使用14pt/px可见内凹把手和20pt/px透明命中窗口；展开态恢复上下严格镜像肩部，窗口高度只保留内容轮廓。
- 底部Settings提示弧、齿轮、悬停状态、命中区和辅助功能入口全部移除；设置继续从应用菜单与悬浮条右键菜单进入。
- Settings新增第五个Floating Strip页签，Windows简中显示“悬浮条”；Appearance精简为通用显示项，悬浮条设置按内容与尺寸、屏幕与位置、行为三组排列。
- 外部入口连续请求同一页签仍会正确重选；Windows五页签在360px窄窗可横向到达，底部控件可滚动访问。
