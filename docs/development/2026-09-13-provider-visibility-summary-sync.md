# 产品可见性与摘要同步

关联需求：REQ-20260913-002。日期：2026-09-13。

## 背景与目标

用户在 Settings 隐藏一个产品后，悬浮条只显示三个产品，但菜单栏或托盘摘要仍显示四个。本次让两个入口共享同一份可见产品顺序，并保持账户与采集数据不变。

## 影响范围

- macOS：菜单栏卡片顺序、可见性和最高用量百分比。
- Windows：托盘菜单摘要行的顺序、可见性和刷新。
- 共用偏好：沿用现有隐藏、排序和持久化格式，不迁移或清除凭据。

## 失败证据

- macOS 新回归最初因缺少可见菜单快照入口而编译失败；原实现的 `MenuBarPanel` 和 `menuBarSummary` 均直接使用全部 `snapshots`。
- Windows 新回归最初因缺少按偏好生成摘要顺序的函数而编译失败；原托盘安装固定创建四个摘要项。

## 实现与关键决定

macOS 在模型层按现有 `visibleProviders` 顺序过滤快照，卡片和菜单栏最高用量共用结果。Windows 使用现有 `visible_providers()` 生成摘要项，并在设置或用量事件后替换托盘菜单，使隐藏、恢复、排序和语言更新一起生效。

## 本机与界面验收

macOS 的可观察模型和真实面板编译路径已覆盖即时更新。Windows 原生托盘的最终绘制仍需 Windows 11 现场确认；本机不冒充 Windows 原生界面验收。
