# 2026-09-11：0.8.0 Mini浮动条稳定发布

关联`REQ-20260911-005`，交付`REQ-20260911-001`至`REQ-20260911-004`。[发布计划](../design/implementation-plans/2026-09-11-v0.8.0-release.md)、[Release Notes](../releases/v0.8.0.md)。

目标为双平台稳定版0.8.0、macOS build23。用户确认65pt Mini方案并明确要求发布，授权覆盖必要提交、推送、PR、main合并、标签、GitHub Release和应用内更新源。

## 候选验证

功能候选新增65pt/px Mini、恢复78pt/px Compact，Comfortable保持108pt/px；旧`compact`偏好继续表示Compact。自动收起开关默认开启，关闭会取消计时并立即展开，延迟值保留。Settings齿轮只由底部深色弧区悬停或键盘焦点显示。

完整本机门禁通过493项Swift、133项Windows前端、246项Rust、24组真实Chrome布局、8种Antigravity详情状态、608个文字角色、production build、格式、严格Clippy、六份合同、269份Markdown、公开安全和0.8.0/build23 arm64严格签名App。浏览器与Rust测试需要本机回环服务器；隔离沙箱准确以EPERM拒绝，允许本机回环后按原命令全部通过，没有跳过或放宽断言。精确候选CI、main CI与正式发布结果将在各步骤完成后追加。

首次独立审查发现两项Important与两项Minor：macOS Settings悬停区过宽、用户指南未同步、Windows旧schema兼容不对称及Compact测试仍使用65宽；全部修复。最终复审为Critical 0、Important 0、Minor 1，唯一测试命名Minor也在候选提交前关闭。
