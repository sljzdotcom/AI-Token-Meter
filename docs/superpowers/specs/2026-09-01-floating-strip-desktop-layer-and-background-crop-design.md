# AI Token Meter 浮动条桌面层与肩部背景连续性设计规格

**日期：** 2026-09-01  
**状态：** 用户已确认设计，等待实现计划  
**范围：** 下一阶段需求 R2、R6  
**基线：** `main` 提交 `970060e`

## 1. 背景与问题

当前浮动条和详情面板使用 `.floating` 窗口层级，并配置：

```swift
[.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]
```

这使浮动条不仅出现在桌面，还会覆盖普通应用窗口，并作为辅助窗口进入 Edge 等应用的全屏 Space。用户要求浮动条表现得像桌面内容：普通应用窗口可以盖住它，全屏应用中不显示。

当前深海背景资产本身包含上下纯黑留边。图片按浮动条的完整 `108 × 356` 画布等比例映射时，黑边正好进入顶部与底部肩部，使顶部反向半圆看起来像没有背景图。用户选择“统一放大裁切”方案，同时明确要求原始图片文件必须完整保留。

## 2. 目标

1. 浮动条和详情只属于 macOS 桌面层，不覆盖普通应用窗口。
2. Edge 或其他应用进入全屏后，浮动条与详情均不显示在全屏内容上方。
3. 浮动条在普通桌面 Space 之间继续可用，并保留左右侧和垂直位置。
4. 切换 Space 时关闭展开的详情，避免返回桌面后显示过期详情。
5. 使用现有深海图片覆盖完整 S 形轮廓，包括上下肩部。
6. 裁掉图片上下黑边时保持等比缩放，不拉伸波纹。
7. 左右贴边时只镜像背景和轮廓，不镜像 Logo、圆环或交互区域。
8. 背景加载失败时继续使用现有玻璃底色。

## 3. 非目标

- 不修改、裁剪、覆盖或重新生成 `floating-strip-deep-sea.png`。
- 不改变 S 形路径、浮动条尺寸、圆环大小、Provider 排序或 Logo。
- 不改变详情自动隐藏时间、外部点击关闭、DeepSeek 登录焦点或数据刷新机制。
- 不在本阶段实现 Settings Tab、产品改名、App Icon 重设计或 WidgetKit。
- 不把浮动条改造成系统 Widget；本阶段仍使用现有 AppKit/SwiftUI 窗口。

## 4. 桌面层窗口语义

### 4.1 窗口层级

浮动条与详情面板都使用桌面图标窗口层级附近的专用级别，而不是 `.floating`：

- 高于桌面壁纸，保证桌面可见；
- 不高于普通应用窗口，保证应用窗口自然覆盖；
- 不加入系统窗口切换循环；
- 不抢占其他应用的正常窗口层级。

窗口层级和集合行为由新的 `FloatingPanelPresentationPolicy` 集中提供。推荐层级使用 `CGWindowLevelForKey(.desktopIconWindow) + 1`，但实现必须用测试或实机验证它仍低于普通应用窗口；如果目标 macOS 的级别关系不同，应选用满足同一行为契约的最近桌面级别，而不是硬保留具体数值。

### 4.2 Space 行为

集合行为使用：

- `.canJoinAllSpaces`：在普通桌面 Space 中持续可用；
- `.stationary`：Mission Control 期间保持桌面式定位；
- `.ignoresCycle`：不进入窗口切换循环。

必须移除 `.fullScreenAuxiliary`。桌面级别与缺少全屏辅助资格共同保证全屏应用覆盖浮动条。

### 4.3 详情行为

详情面板使用与浮动条相同的桌面层语义。用户只能从桌面可见的浮动条打开详情：

- Claude、Codex 继续保持只读非抢焦点行为；
- DeepSeek 仍可在打开登录页面时获得必要键盘焦点；
- 普通应用窗口可以盖住详情；
- 全屏应用不能被详情覆盖。

### 4.4 Space 变化

`FloatingPanelController` 监听 `NSWorkspace.activeSpaceDidChangeNotification`。每次 Space 变化时：

1. 关闭当前详情并使详情面板 `orderOut`；
2. 不改变浮动条保存的屏幕、侧边和垂直位置；
3. 重新计算浮动条位置，适配当前可用屏幕；
4. 保持浮动条本身已排序，普通桌面可见，全屏时位于全屏窗口后方。

观察者必须在控制器销毁时注销，不能留下重复通知或悬空回调。

## 5. 背景统一放大裁切

### 5.1 原始资产保护

受保护资产：

```text
Sources/AIMeterApp/Resources/Backgrounds/floating-strip-deep-sea.png
```

当前基线：

- 像素尺寸：`324 × 1068`
- SHA-256：`43ae960bf58a5ddcf2b416362c00d7bfcdcc5764f9af50316285454b2a813b6d`

实现提交不得包含该文件的二进制变化。规格中的哈希用于本阶段验收资产未被替换，不建立永久禁止未来品牌设计修改的产品规则。

### 5.2 缩放规则

原图上下各约有 96 像素纯黑留边，对应 3× 资源下约 32pt。运行时将背景从中心等比放大约 `1.22×`：

```text
1068 / (1068 - 96 - 96) ≈ 1.219
```

实现使用统一常量，例如 `contentScale = 1.22`。禁止只做纵向拉伸。

### 5.3 渲染顺序

1. 绘制现有玻璃底色作为 fallback；
2. 背景图片以 `scaledToFill` 填满浮动条画布；
3. 以中心为锚点应用 `1.22×` 等比缩放；
4. 右侧贴边使用正向水平比例，左侧贴边叠加负水平比例；
5. 应用现有暗色 scrim；
6. 对完整 `FloatingStripShape` 统一裁切；
7. 在独立前景层绘制三个 Provider 按钮。

图片缩放后的左右内容会被轻微裁切，这是用户已批准的方案 A 权衡。不得为保留左右内容而改成非等比拉伸。

## 6. 组件边界

### `FloatingPanelPresentationPolicy`

- 负责窗口级别、集合行为和进入窗口循环的规则；
- 提供可单元测试的值，不拥有窗口或应用状态；
- 同一策略用于 strip 和 detail，除现有激活/键盘能力外不产生分叉。

### `FloatingPanelController`

- 应用窗口策略；
- 注册和注销活动 Space 观察者；
- Space 变化时关闭详情并重新定位；
- 继续负责现有拖动、详情开关和外部点击逻辑。

### `FloatingStripBackgroundPresentation`

- 保存统一背景缩放常量；
- 根据侧边返回带正负方向的等比缩放；
- 不加载资产、不修改 S 形路径、不知道 Provider 内容。

### `FloatingStripSurface`

- 按规定顺序合成玻璃、图片、scrim 和形状裁切；
- 继续支持注入合成图片，以便测试黑边裁切；
- 装饰性背景保持 `accessibilityHidden(true)`。

## 7. 状态流

1. 应用启动，控制器从持久化位置创建桌面层浮动条。
2. 普通桌面 Space 中，浮动条位于壁纸/桌面层之上、普通应用窗口之下。
3. 用户露出桌面并点击 Provider，详情按现有规则展开。
4. 用户打开普通应用，应用窗口自然盖住浮动条和详情。
5. 用户进入全屏或切换 Space，Space 通知关闭详情；浮动条不能出现在全屏应用上方。
6. 返回普通桌面，浮动条继续使用保存的侧边和垂直位置。

本阶段不新增用户偏好或持久化字段。

## 8. 降级与错误处理

- 背景资产缺失或加载失败：显示现有玻璃 fallback，不显示空白或崩溃。
- 无可用屏幕：沿用现有安全返回；下一次屏幕参数变化时重新定位。
- Space 通知重复或快速触发：详情关闭操作必须幂等，不能重复创建面板。
- DeepSeek 正在交互时发生 Space 切换：立即结束详情会话并撤销焦点，不能让 WebView 留在不可见 Key Window。
- Mission Control 或全屏过渡动画期间窗口暂时重新排序：最终结果以桌面层级为准，不通过提高窗口层级抢回前景。

## 9. 自动化测试

### 窗口策略

- 集合行为包含 `.canJoinAllSpaces`、`.stationary`、`.ignoresCycle`；
- 集合行为不包含 `.fullScreenAuxiliary`；
- 策略窗口层级低于普通应用窗口层级；
- strip 与 detail 使用同一桌面层语义；
- Space 变化关闭详情但不改写持久化位置；
- 控制器注销 Space 观察者。

### 背景

- 使用上下黑边、中间蓝色的合成图片渲染 `FloatingStripSurface`；
- 方案 A 缩放后，顶部和底部肩部采样点都必须取得有效蓝色内容；
- 缩放在 X/Y 方向绝对值相同，证明没有纵向拉伸；
- 左右侧的水平比例符号相反，垂直比例相同；
- Provider Logo、圆环、交互区域不在背景镜像层中；
- 背景缺失仍显示玻璃 fallback；
- 原有形状边界、无外部阴影、拖动和点击测试继续通过；
- 受保护 PNG 的工作区文件与基线 SHA-256 一致，且 Git diff 不包含该文件。

## 10. 实机验收

安装候选版后逐项检查：

1. Finder 桌面可见并可点击浮动条；
2. 普通 Edge 窗口覆盖浮动条，不被浮动条压在上方；
3. Edge 全屏中完全看不到浮动条和详情；
4. 返回桌面后浮动条仍保持原位置；
5. Mission Control 不出现悬浮在 Space 缩略图上方的异常窗口；
6. 左右两个普通 Space 均按桌面语义显示；
7. 打开详情后切换 Space，返回时详情保持关闭；
8. 左右贴边分别检查上下肩部都有连续蓝色波纹；
9. Logo、圆环、点击和拖动方向正常；
10. 背景失败注入测试仍显示玻璃底色；
11. 重启后字体 Antonio、右侧偏好和 97% 垂直位置不受影响；
12. 有多显示器时检查显示器切换；没有第二台显示器时明确记录为环境未覆盖。
