# Claude 详情隐私说明移除设计规格

**日期：** 2026-09-02
**状态：** 待用户最终确认
**需求：** `REQ-20260902-009`

## 1. 背景

Claude 详情页的本机活动区域目前在每日 Token 趋势下方显示一条带锁形图标的隐私说明：

`Only aggregate timestamps, token counts, session IDs and model IDs are read. Conversation content stays private.`

用户已选择方案 A，要求把整条说明从详情页移除。

## 2. 目标行为

1. 删除隐私说明文字；
2. 同时删除同行的锁形图标；
3. 不保留空白、占位符、悬停提示或设置开关；
4. 删除后，每日趋势与页脚按照现有间距自然相邻；
5. 官方额度、Sessions、Active days、Tokens、每日趋势、空状态、采集状态和更新时间保持不变。

## 3. 边界与兼容性

本次只修改 `ClaudeDetailView` 的展示层及对应回归测试。以下内容不变：

- `ClaudeLocalActivityReader` 的白名单字段和资源边界；
- 不读取聊天正文、提示词、回复、项目路径等内容的隐私约束；
- Claude 本机活动领域模型、缓存结构和旧数据兼容；
- 窗口宽高、滚动区域、置前、点击空白关闭和自动隐藏行为。

用户界面不再重复显示隐私说明，但项目文档中的隐私边界继续保留。

## 4. 测试与验收

采用测试驱动实现：

1. 先把现有源码契约改为断言隐私说明和 `lock.shield` 不存在；
2. 在生产代码仍保留说明时运行定向测试，确认因预期内容仍存在而失败；
3. 删除 `Label` 后再次运行定向测试，确认通过；
4. 完整测试不得出现回归；
5. Release 构建、签名、安装版哈希与真实 Claude 详情开关行为通过；
6. 用户指南、变更日志、开发日志和需求台账同步更新。

## 5. 非目标

- 不改变或弱化底层隐私保护；
- 不移除其他页面中的隐私说明；
- 不重新排版 Claude 详情的其他卡片；
- 不增加新的偏好设置。
