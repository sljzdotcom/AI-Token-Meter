# 菜单栏 Quantum Dial 图标设计规格

**日期：** 2026-09-02  
**状态：** 已实施并验收
**需求：** `REQ-20260902-010`

## 1. 背景

AI Token Meter 当前使用 SF Symbols 的 `gauge.with.dots.needle.50percent` 作为菜单栏图标。它能够表达“仪表”含义，但外观接近系统通用图标，品牌辨识度和现代极客感不足。

用户已在三套实尺寸视觉原型中选择方案 A「Quantum Dial」，并确认图标应动态表达三项服务中最高的已用比例。

## 2. 目标

1. 用自绘 `Quantum Dial` 替换菜单栏顶部的通用仪表图标；
2. 在 macOS 菜单栏 18×18pt 的实际尺寸下保持轮廓清楚、线条稳定；
3. 图标动态反映三项服务中最高的有效已用比例；
4. 保留菜单栏旁边的精确百分比文字；
5. 自动适配浅色、深色及系统高亮状态；
6. 不改变额度计算、数据刷新、菜单弹出面板和其他品牌图标。

## 3. 视觉构成

`Quantum Dial` 由以下单色元素组成：

- 一条留有开口的圆形轨道；
- 沿轨道分布的三枚短刻度；
- 一个中心轴点；
- 一根由中心轴指向当前用量位置的指针；
- 覆盖在轨道上的动态进度弧。

图标使用 macOS 菜单栏前景色，不在菜单栏中使用彩色渐变。轨道以较低不透明度显示，进度、刻度、中心轴和指针使用主要前景强度。图标不得依赖颜色传递额度状态。

固定画布为 18×18pt。所有笔画使用圆角端点和圆角连接，避免在 Retina 与非整数缩放下产生尖角或破碎像素。图标不设置外部阴影、背景底板、描边方框或持续动画。

## 4. 动态行为

`MenuBarSummary` 继续从所有可用 Provider 中选择最高的有效已用比例。展示模型新增独立的可选比例值，视图直接消费该数值，不从 `"23%"` 文本反向解析。

### 4.1 有效比例

- 输入比例先限制在 `0...1`；
- 进度弧长度随比例线性增长；
- 指针在预留开口之外的有效角度区间内线性旋转；
- `0%`、`100%` 和越界输入均有确定的端点结果；
- 旁边继续显示现有整数百分比，例如 `23%`。

### 4.2 无有效数据

当三项服务都没有有效用量比例时：

- 仍显示基础断环与三枚刻度；
- 不显示动态进度弧；
- 指针回到中性水平位置；
- 旁边继续显示现有 `—`；
- 辅助功能文案继续说明 usage unavailable。

### 4.3 刷新与能耗

图标只在 `MenuBarSummary` 变化时重绘。刷新完成后图标和百分比同步更新，不增加计时器、循环动画或独立轮询。

## 5. 组件边界

### 5.1 展示模型

`MenuBarSummary` 负责提供：

- 现有 `semantic`；
- 现有 `valueText`；
- 现有 `accessibilityLabel`；
- 新增的可选规范化用量比例。

比例选择逻辑仍只有一个来源，避免图标和文字出现不一致。

### 5.2 图标视图

新增专用 `MenuBarMeterIcon`，只负责根据可选比例绘制轨道、进度、刻度、中心轴和指针。几何计算与 SwiftUI 渲染分离，使角度和边界可以通过纯测试验证。

`MenuBarLabel` 使用新图标，但保留当前 `Label`、百分比文字、字体作用域和辅助功能标签。

### 5.3 保持不变

- 菜单栏点击后弹出的面板；
- 弹出面板无数据状态使用的内部图标；
- 应用程序 Icon；
- Claude、Codex、DeepSeek Logo；
- 浮动条、详情页和 Widget；
- Provider 额度与余额算法；
- 正常、警告、严重、过期和不可用的既有语义判断。

## 6. 无障碍与系统适配

- `MenuBarLabel` 继续使用 `MenuBarSummary.accessibilityLabel`，不让 VoiceOver 朗读内部绘图元素；
- 自绘图标整体标记为装饰性，防止出现重复辅助功能节点；
- 使用系统前景色和不透明度而非固定黑白值；
- 菜单栏被点击或系统反转前景色时，图标整体随系统变化；
- 百分比文字仍是精确、非颜色依赖的信息来源。

## 7. 测试与验收

采用测试驱动实现：

1. 先增加 `MenuBarSummary` 比例输出测试，覆盖最高比例选择、不可用 Provider 排除、无数据、负数和大于 100% 的夹紧；
2. 增加图标几何测试，覆盖 `0%`、`23%`、`70%`、`90%`、`100%` 和无数据状态；
3. 通过真实展示模型、几何与渲染测试保护新组件；删除已经失效的旧 SF Symbol 源码字符串断言，不再用源码搜索代替行为验证；
4. 对浅色和深色前景执行渲染检查，并由系统前景色保证高亮状态继承，确认 18×18pt 下没有裁切、断线或背景方块；
5. 完整自动化测试、Release 构建、签名和安装哈希必须通过；
6. 在真实菜单栏观察有效用量与无数据状态，确认图标、百分比文字、点击区域和弹出面板行为正常。

## 8. 非目标

- 不重新设计菜单栏弹出面板；
- 不增加图标样式选择器；
- 不为图标加入彩色主题、发光或动画；
- 不修改通知阈值或 Provider 排序；
- 不把这套图形扩展到应用 Icon、浮动条或 Widget。
