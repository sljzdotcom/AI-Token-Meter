# AI Token Meter 0.10.5

稳定修复版；macOS build 33。macOS Antigravity现在明确区分当前采集、最近缓存额度与持久刷新暂停，并提供本地阶段诊断；Windows运行行为保持不变。

## 修复

- Services与详情页不再把缓存额度表达为当前Connected；保留原始额度采集时间，并在刷新暂停后立即说明原因。
- 只有明确认证错误才提供 **Sign in to Antigravity**。超时、网络/进程错误、限流、无效响应与未知旧状态继续暂停，不提供会误导用户的登录、安装或重试操作。
- Services与详情页可复制本地诊断摘要，只含固定阶段/结果、耗时与截断标记；不包含命令输出、路径、环境值、账户信息或令牌。记录最多20条、文件不超过16KiB。
- 任一Antigravity失败仍持久暂停；网络错误和超时不会恢复自动重试，继续保留防止浏览器弹窗重复出现的保护。
- Windows安装器目前没有 Authenticode 发布者证书，因此首次安装仍可能出现 SmartScreen “unknown publisher”提示；请从本项目 GitHub Release 下载并核对 SHA-256，应用内更新仍使用 Tauri 签名校验。

## 平台与验证范围

- macOS：包含缓存/连接/暂停状态、原因分类、隐私安全诊断与有条件恢复入口。
- Windows：仅同步共享应用版本；运行行为保持不变。
- 自动化验证不能替代 M4 Max 用户设备上的现场验收；真实 `agy` 与 Google OAuth 未由本次发布流程启动。

完整CI、签名资产、SHA-256和三个更新源的证据见[发布记录](../development/2026-10-01-antigravity-status-and-diagnostics-release.md)。
