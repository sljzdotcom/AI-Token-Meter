# AI Token Meter 0.10.3

0.10.3是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build31。macOS现在会发现新版ChatGPT.app内嵌的Codex CLI；账户状态、额度读取和登录入口使用相同的发现逻辑。Windows产品行为保持不变，并同步提供更新版本。

## macOS

- 在用户级 `~/Applications/ChatGPT.app` 和系统级 `/Applications/ChatGPT.app` 中发现嵌套的Codex CLI。
- 保留既有可执行文件搜索路径及顺序；旧候选无效时继续检查新路径。
- 账户状态、用量采集和Codex登录入口共用相同的CLI发现结果。
- 不修改 shell PATH、`~/.local/bin/codex` 链接、Codex账户或凭据。

## Windows

- 产品功能和界面保持0.10.2不变，仅同步版本、安装包与应用内更新信息。

## 下载

- macOS Apple Silicon：`AI-Token-Meter-0.10.3-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.10.3-windows-x64-setup.exe`

请同时下载对应的`.sha256`文件核对完整性。应用内升级会校验Sparkle或Tauri更新签名。

macOS公开包沿用Apple Silicon、ad-hoc签名、未公证且不含Widget的发布配置；Windows安装器的签名状态以本版公开资产验证记录为准。

Windows安装器没有Authenticode签名，首次安装可能出现SmartScreen `unknown publisher`提示；请使用随附SHA-256核验下载文件。应用内更新仍由Tauri更新签名验证。
