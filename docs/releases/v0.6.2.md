# AI Token Meter 0.6.2

0.6.2 是 macOS Apple Silicon 与 Windows 11 x64 的稳定品牌补丁版，macOS build17。本版在两端常用的菜单面板顶部加入现有应用 Logo，让产品身份更清楚，同时保留原有信息密度和操作位置。

## 菜单面板品牌展示

- macOS菜单栏弹出面板在“AI Token Meter”标题和副标题左侧显示32pt现有应用Logo，使用透明容器，不增加底板、边框或阴影。
- Windows原生托盘菜单以同一默认图标和“AI Token Meter”作为顶部品牌行，品牌行不可点击，后接原生分隔线。
- 刷新按钮、四服务用量摘要、设置、浮动条开关、关于与退出操作保持；没有增加网络请求、用户数据或凭据处理。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.6.2 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.6.2-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.6.2-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、用户设置或凭据存储位置。

## 使用边界

交互式Windows 11原生菜单观感和多DPI仍需在对应物理环境验收。Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。这些分发边界不影响应用内更新签名验证。
