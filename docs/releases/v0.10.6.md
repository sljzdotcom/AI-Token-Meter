# AI Token Meter 0.10.6

稳定修复版；macOS build 34。测试进程的系统打开默认拒绝，Antigravity本地诊断摘要包含经过安全校验的应用版本和build。macOS正式用户显式登录流程保持不变，Windows运行行为保持不变。

## 修复

- 测试中即使遗漏登录/安装操作的模拟注入，也不会打开真实Terminal、浏览器、登录脚本或外部链接。测试脚本目录使用唯一临时位置。
- Services或Antigravity详情页复制诊断时会附带 `appVersion` 与 `build`，便于定位设备运行的发行版。非法或异常包元数据统一显示 `unknown`。
- 旧暂停继续保持暂停；历史阶段没有记录时仍显示未知，不推断认证失效、额度耗尽或实际超时原因。

## 平台说明

- macOS：仅在测试环境默认禁止系统外部打开；正式用户主动登录/安装的流程保持不变。
- Windows：产品运行行为不变，仅与macOS共享版本号及发布资产。

Windows安装程序目前没有 Authenticode 发布者证书，首次安装可能显示 SmartScreen “unknown publisher”提示。请从项目 GitHub Release 下载并核对 SHA-256；应用内更新仍使用 Tauri 签名校验。

公开资产、签名、SHA-256和三个更新入口的验证证据将在正式Release完成后补入开发记录。
