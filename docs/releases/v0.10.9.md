# AI Token Meter 0.10.9

双平台稳定修复版；macOS build 37。修复 Antigravity 单次登录恢复中的回执失败等待，并改善缺少共享额度时的提示。自动刷新暂停仍遵循原有安全行为。

## 修复

- 登录脚本无法把结果回执送回应用时，Services 会结束等待并显示登录失败提示；不必再等到数分钟超时。
- Antigravity详情已有Gemini额度、但CLI未返回Claude/GPT共享窗口时，会显示明确说明。
- 脚本阶段提示覆盖启动、等待应用交接、启动CLI、登录结果和回执错误。

## 暂停与恢复

- 单次官方登录及只读额度检查成功后，自动刷新仍保持暂停。版本发布不会清除未知暂停或自动恢复周期刷新。
- 旧诊断 `refreshPaused=true reason=unknown` 表示刷新仍处于暂停，但不能还原原始根因。请核对应用版本及最后一次成功额度时间。
- 真实 `agy 1.3.1` 输出格式及现场Claude/GPT共享额度未在开发机确认；如CLI只返回Gemini额度，详情会提示共享窗口当前不可用。

## 平台

- macOS：Apple Silicon，macOS 14 或更新版本。
- Windows：Windows 11 x64；安装器没有 Authenticode 发布者证书，首次安装可能显示 SmartScreen 的 “unknown publisher” 提示。请从项目 GitHub Release 下载并核对 SHA-256。
- 正式安装包、签名和更新源以发布记录为准。
