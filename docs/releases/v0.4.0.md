# AI Token Meter 0.4.0

## 新功能与修复

- macOS 与 Windows 支持主显示器、指定显示器、所有显示器三种展示方式，每屏分别记住贴边方向和高度。
- 修复 macOS 固定左/右贴边时无法跨屏拖动；指定屏断开临时回到系统主屏，重连恢复原位置。
- Windows 增加 English / 简体中文即时切换；新安装默认微软雅黑，可选择黑体、楷体，已有字体偏好保留。Settings 始终使用系统字体。
- Windows 所有服务详情文字统一再减小 1 CSS px，macOS 字号保持不变。

## 更新与安装

已有设备在 Settings → About → Check for Updates 检查，再选择 Update Now。macOS 稳定和旧 Preview、Windows 稳定和旧 Preview 使用原有更新入口，无需安装中间版本。macOS build 为 12。

- macOS Apple Silicon：下载本版 `macOS-arm64.zip`。
- Windows x64：下载本版 `windows-x64-setup.exe`。
- 手动下载请核对同名 SHA-256 文件。应用内更新继续分别验证 Sparkle / Tauri 签名，未更换公钥。

## 已知边界

macOS 仍为 ad-hoc 签名、未公证，Windows 尚无 Authenticode 发布者签名，首次安装可能出现 Gatekeeper/SmartScreen 提示。Widget 证书延期，本版不包含可安装 Widget。实际多显示器拔插、Windows DPI/字体专项仍待对应设备验收；不能把自动化通过当作所有真机环境已验证。
