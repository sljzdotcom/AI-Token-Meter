# AI Token Meter 0.11.0

macOS build 40。macOS 新增第五个可选服务 Code0。Windows 本版未发布，产品行为与 0.10.11 相同；Windows 相关改动仍在后续批次中，不随本版提供。

## Code0（macOS 首发）

- Code0 是可选服务：只有在 Settings → Services 中由用户显式连接后，App 才会打开 Code0 官方网页；登录由用户在官方页面自行完成，未连接或未登录时应用不采集任何 Code0 数据。
- 展示的是 **Code0 站内额度（siteCredits）**，不是美元：不与 API 计费换算、不做汇率折算、不给出美元估值或充值额推算，读数以官方站点自身的配额单位呈现。
- 只读取余额与累计消耗等必要字段。不猜测未公开接口、不发起付费探测、不探测 `/api/user/token`；相邻两次读取间隔不少于 300 秒；应用重启后保持暂停，需用户再次确认。
- 不导出或另存 Cookie、原始个人字段；会话凭证留在隔离网页的官方登录态内。
- 服务页与详情页展示余额与累计消耗，支持英语、简体中文与繁体中文；设计边界见[Code0 监控设计](../design/specifications/2026-10-26-code0-monitor-design.md)。

## 已知限制

- 未覆盖真实媒体权限委托与 TCC 分支，不据此声称真实的授权或拒绝行为。
- 未覆盖真实 TLS 握手与客户端证书回调的先后顺序。
- 未用真实账号与真实余额验收；当前读数来自受控夹具，真实账户结果以设备实际检查为准。
- 未覆盖 401、重定向、弹窗、下载、页面对话框与权限提示的原生组合全矩阵。

## 安装与更新

macOS Apple Silicon ZIP 使用 Sparkle 更新签名，应用包为 **ad-hoc signed** 且 **not notarized**，不声明 Developer ID；首次打开若被 macOS 阻止，请在 Finder 中右键 App 选择“打开”。

Windows 本版未发布，不提供 Windows 安装器。后续 Windows 批次仍沿用现有边界：没有 Authenticode 发布者证书，安装器可能出现 SmartScreen 的 unknown publisher 提示；应用内 Windows 更新另由 Tauri minisign 签名验证保护。

更新不会自动清除旧的暂停状态或已有登录凭据。所有 Provider 均为可选，未配置时不采集对应数据。
