# AI Token Meter 0.10.8

稳定版；目标为 macOS build 36。Antigravity 详情增加官方 `/usage` 中 Claude/GPT 共享额度窗口；Gemini 与独立 Claude Code/OpenAI Codex 的额度口径保持不变。

## 新增

- Antigravity 详情分别展示 Claude/GPT 共享池的五小时与每周剩余额度及重置时间。没有共享池数据时隐藏该区域；不发送模型请求。
- Gemini 仍是 Antigravity 的主指标、圆环和提醒来源。

## 暂停与恢复

- Antigravity 自动刷新暂停逻辑保持不变；应用会尝试持久化暂停状态，但写盘失败时无法保证重启后仍处于暂停。本版本不代表自动刷新或现场额度恢复已修复。
- 旧版 `refreshPaused=true reason=unknown` 诊断可能没有保存原始失败阶段或原因；请核对诊断中的应用版本和最后成功额度时间。受控单次恢复入口从 0.10.7 起提供；成功读取一次额度后，本次运行仍保持暂停。
- Windows 新增相同的共享额度详情；其采集与自动刷新行为不变。

## 发布验证边界

- 不运行真实 `agy`、不登录 Google 账号，也不读取或修改用户设备上的 CLI、账号或应用状态。
- 正式 macOS/Windows 签名安装包、更新源与公开下载校验值以发布记录为准。

## 平台说明

- macOS：Apple Silicon，macOS 14 或更新版本。
- Windows：Windows 11 x64；安装器没有 Authenticode 发布者证书，首次安装可能显示 SmartScreen 的 “unknown publisher” 提示。请从项目 GitHub Release 下载并核对 SHA-256。
