# AI Token Meter 0.6.1

0.6.1 是 macOS Apple Silicon 与 Windows 11 x64 的稳定修复版，macOS build 16。本版让 Claude Code、OpenAI Codex、DeepSeek 与 Gemini 的首次安装、登录、凭据配置和错误恢复更清楚、更一致。

## 接入与恢复改进

- Claude Code、OpenAI Codex 或 DeepSeek 需要安装、登录、API Key 或其他设置时，详情页可直接打开 Settings → Services，并自动选中对应页面。
- 账户状态无法检查时，每张服务卡只显示一个 **Check Status / 检查状态**，避免重复操作。
- DeepSeek 初次配置显示 **Save API Key**，已有 Key 时才显示 **Replace API Key**；首次验证失败不会声称旧 Key 仍被保留。
- DeepSeek 余额凭据与官网 30 天历史登录保持分离。缺少 API Key 时先引导打开 Services，已有历史数据继续保留。
- Windows 在 DeepSeek Key 验证期间锁定同一事务，防止重复提交或旧结果覆盖；候选 Key 仍只在原生凭据界面与 Rust 后端内处理。

## Gemini 安装引导

- Gemini 安装按钮直达[官方安装指南](https://geminicli.com/docs/get-started/installation/)，不再打开额度说明页。
- 缺少 CLI 时明确提示 Node.js 20 或更高版本，并给出本程序验证的固定安装命令：`npm install -g @google/gemini-cli@0.58.0`。
- 安装后运行 `gemini`，选择 **Sign in with Google**，再回到 Settings → Services 点击 **Retry / Check Status**。
- 已安装但需要登录时只显示登录步骤；连接成功后隐藏安装步骤。普通网络失败保留最近快照，不误导用户重装。

应用不会自动安装或升级 CLI，不会代用户登录、回答权限提示或修改现有凭据。

## 更新方法

macOS：Settings → About → Check for Updates，然后按 Sparkle 提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧 Preview 入口使用同一份 0.6.1 Windows 更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.6.1-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.6.1-windows-x64-setup.exe`

手动下载时可核对同名 SHA-256 文件；应用内更新继续验证原 Sparkle/Tauri 更新签名。版本升级不会改变应用身份、更新地址、公钥、用户设置或凭据存储位置。

## 使用边界

Gemini 仍固定支持官方 CLI 0.58.0 的普通 Google OAuth 模式；Windows 首期只支持原生 CLI，不覆盖 WSL、API Key、Vertex AI、企业或外部认证模式。本轮自动化不代用户登录真实账号或消耗额度。

Windows 安装包暂未使用 Authenticode 发布者证书，首次手动安装可能出现 SmartScreen 的 unknown publisher（未知发布者）提示。macOS 包使用 ad-hoc 签名、未公证且不含 Widget；首次手动打开可能需要在 Finder 中右键选择“打开”。这些分发边界不影响应用内更新签名验证。
