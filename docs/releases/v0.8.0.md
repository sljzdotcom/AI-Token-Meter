# AI Token Meter 0.8.0

0.8.0是macOS Apple Silicon与Windows 11 x64的稳定功能更新，macOS build23。本版把已确认的65pt/px视觉作为独立Mini档，恢复78pt/px Compact，并允许关闭浮动条自动收起。

## 新功能与修复

- Appearance固定提供Comfortable、Compact、Mini三档，宽度分别为108、78、65pt/px；Mini与Compact使用48pt/px圆环，Comfortable使用60pt/px圆环。
- 已有`compact`设置升级后继续表示Compact并使用78pt/px，不会自动改成Mini；需要65pt/px时可主动选择Mini。
- 新增“自动收起浮动条”开关，默认开启。关闭后浮动条立即展开并保持展开，原显示/收起延迟值会保留，重新开启后继续使用。
- Settings提示弧改为深色；只有底部弧区悬停或键盘焦点会显示齿轮，浮动条主体悬停只负责展开。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.8.0 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.8.0-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.8.0-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、Provider顺序、显示器位置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。物理Windows 11多屏和不同DPI继续保留现场观察边界。
