# AI Token Meter 0.10.2

0.10.2是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build30。本版让macOS悬浮条的Liquid Glass恢复清透层次，并修复带Widget正式构建的签名权限校验误报。Windows产品界面保持不变，同步提供0.10.2安装包和应用内更新。

## macOS

- Liquid Glass不再叠加76%–88%的深蓝黑烟熏底板，桌面内容可以透过系统玻璃自然显现。
- 普通模式保留12%冷蓝tint和细边缘高光，兼顾透明感与轮廓可见度。
- macOS 26继续使用原生Liquid Glass；macOS 14–15使用系统超薄材质回退。
- 开启“降低透明度”时继续使用原有不透明深色表面，保证可读性。
- Widget正式打包会精确核对宿主和扩展签名中的App Group，避免正确签名被数组文本格式误报。

## Windows

- 产品行为与视觉保持0.10.1不变。
- 同步版本、签名更新清单与稳定更新入口，可从旧版直接升级。

## 下载

- macOS Apple Silicon：`AI-Token-Meter-0.10.2-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.10.2-windows-x64-setup.exe`

请同时下载对应的`.sha256`文件核对完整性。应用内升级还会校验Sparkle或Tauri更新签名。

Windows安装器尚无Authenticode，首次安装可能出现SmartScreen `unknown publisher`提示；可用随附SHA-256核验文件。macOS公开包为ad-hoc签名、未公证且不含Widget，首次安装可能需要在Finder中右键打开。
