# AI Token Meter 0.3.0-preview.0

AI Token Meter `0.3.0-preview.0` 是首个 macOS 与 Windows 同版本、同 GitHub Release 的公开预览版。它把已验证的 macOS 功能、Windows 11 x64 客户端和稳定显示器位置恢复放入同一发布门禁。

## 主要变化

- 新增 Windows 11 x64 客户端：系统托盘、左右贴边浮动条、三服务详情、分类 Settings、Native/WSL CLI 发现、Credential Manager 和手动签名更新。
- macOS 与 Windows 统一使用 `0.3.0-preview.0`，共享 Provider Schema、展示合同、fixture、对等矩阵和发布检查。
- 浮动条按稳定物理显示器身份保存目标屏、贴边侧和相对高度。重启、休眠、主屏角色变化或屏幕枚举变化不会覆盖用户位置。
- 目标显示器断开时只临时回到当前主屏；重新接入后恢复原屏、原侧和原高度。
- Windows DeepSeek 详情可在隔离 WebView2 会话中聚合官网最近 30 天成本、请求和 Token；API Key 只保存在当前用户 Credential Manager。
- 加固 macOS PTY 与 DeepSeek Keychain 并发截止时间，减少高负载下的假性超时和输出缺失。

## 下载与安装

在 [GitHub Release](https://github.com/sljzdotcom/AI-Token-Meter/releases/tag/v0.3.0-preview.0) 下载对应平台资产：

- macOS Apple Silicon：`AI-Token-Meter-0.3.0-preview.0-macOS-arm64.zip` 与同名 `.sha256`；
- Windows 11 x64：`AI-Token-Meter-0.3.0-preview.0-windows-x64-setup.exe` 与同名 `.sha256`。

macOS 包仍为 ad-hoc signed、not notarized，首次运行可能需要在 Finder 中右键选择“打开”。Windows 安装器使用 current-user NSIS，不要求管理员权限。

## 更新与签名

- macOS ZIP 由 Sparkle EdDSA 签名；稳定更新源仍保持在 `appcast.xml`，安装 Preview 使用 Release 手动下载。
- Windows updater archive 使用 Tauri minisign 签名，并由应用内置公钥验证；Preview 读取独立的 `windows-preview-feed`。
- Windows 安装器尚无 Authenticode 发布者签名，SmartScreen 可能显示 unknown publisher。minisign 保护应用内更新内容，但不能替代 Authenticode 的发布者身份。
- 两个平台都不会后台静默安装，更新仍由用户在 Settings 中手动检查并明确开始。

## 已知限制

- Windows 11 交互式真机的视觉、DPI、拖动、全屏隐藏、三服务和 DeepSeek 官网登录仍需在真实用户会话中逐项验收。
- Windows `preview.0 → preview.1` 原位升级、设置/凭据保留和错误签名拒绝需要下一份 Preview 才能完成闭环。
- macOS Widget 源码保留，但公开包不含需要 Apple Development 证书与 App Group 的 Widget。
- Windows Widget 不在本 Preview 范围。
