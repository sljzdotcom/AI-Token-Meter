# AI Token Meter 0.10.0

0.10.0是macOS Apple Silicon与Windows 11 x64的稳定功能版，macOS build28。本版为macOS悬浮条增加可选的B款烟熏深色Liquid Glass；Windows界面和悬浮条外观保持不变。

## 变化

- macOS Settings → Floating Strip新增Floating strip appearance，可选Deep Sea（默认）与Liquid Glass。
- 选择后已展开或收起的悬浮条立即更新，重启后保留；旧偏好和未知值安全使用Deep Sea。
- macOS 26使用系统Liquid Glass并叠加稳定的烟熏深色基底；macOS 14–15使用相近系统材质，减少透明度时使用不透明底板。
- Comfortable与Compact尺寸、左右圆润肩弧、圆环、拖动和自动收起行为保持不变。
- Windows只同步0.10.0版本与签名安装包，不增加玻璃设置或渲染效果。

## 更新与安装

- macOS：Settings → About → Check for Updates → Update Now。
- Windows：Settings → About → Check for Updates → Update Now。
- macOS Apple Silicon：`AI-Token-Meter-0.10.0-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.10.0-windows-x64-setup.exe`

Windows安装器尚无Authenticode，首次安装可能出现SmartScreen `unknown publisher`提示；可用随附SHA-256核验文件。macOS包为ad-hoc签名、未公证且不含Widget，首次安装可能需要在Finder中右键打开。
