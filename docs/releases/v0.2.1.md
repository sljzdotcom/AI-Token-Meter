# AI Token Meter 0.2.1

AI Token Meter 0.2.1 是更新功能发布后的稳定性补丁，增强 Claude Code 与 OpenAI Codex 所依赖的本机终端命令执行链路。

## 修复

- 高负载时不再只依赖可能延迟的 Foundation 退出回调；增加独立系统队列确认子进程退出，避免误报超时。
- PTY 非阻塞读取遇到短暂空档时继续有限排空，避免终端回显与真实输出之间的尾部内容丢失。
- macOS PTY 分配的极短临界区保持串行，命令执行和三服务刷新仍可并行。
- 完整验证把 350 项普通测试与 11 项 PTY 系统资源测试分进程执行，覆盖保持 361 项。

## 安装与更新

- 已安装 `0.2.0`：Settings → About → **Check for Updates**，发现 `0.2.1` 后点击 **Update Now**。
- `0.1.2` 或更早版本：下载 `AI-Token-Meter-0.2.1-macOS-arm64.zip` 与同名 `.sha256`，验证后手动替换一次。

当前发行支持 Apple Silicon 与 macOS 14+，为 ad-hoc signed、not notarized。首次运行如果 macOS 阻止，请在 Finder 中右键 App 并选择“打开”。

## 安全与隐私

- 更新归档继续使用 Sparkle EdDSA 签名，签名、版本、build 或长度不匹配时不会替换当前 App。
- 应用仍只在用户点击 **Check for Updates** 后访问 GitHub，不做后台检查或静默安装。
- 本次修复不新增网络、日志、凭据读取或数据持久化。

完整变化见 [CHANGELOG](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/CHANGELOG.md)，安装与排障见[用户指南](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/docs/user-guide/getting-started.md)和[故障排查](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/docs/user-guide/troubleshooting.md)。
