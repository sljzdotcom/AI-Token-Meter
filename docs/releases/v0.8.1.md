# AI Token Meter 0.8.1

0.8.1是macOS Apple Silicon与Windows 11 x64的稳定界面更新，macOS build24。本版简化贴边悬浮条轮廓，取消底部Settings图标，并把悬浮条专属设置移入独立页签。

## 新功能与修复

- 收起态改为14pt/px可见内凹把手，并保留20pt/px透明命中宽度，贴边后更容易发现和展开。
- 展开态恢复上下严格镜像的平滑肩部，窗口高度随内容结束，不再为底部入口保留额外区域。
- 移除底部Settings提示弧、齿轮和悬停入口；鼠标移入悬浮条时不会显示设置图标。
- Settings新增Floating Strip页签，Windows简体中文显示“悬浮条”；服务显示与顺序、三档尺寸、屏幕与位置、自动收起和延迟集中在该页。
- Appearance只保留通用显示设置。悬浮条右键Settings直接打开新页签，服务恢复入口仍打开Services。
- Windows窄窗口可横向访问全部五个页签，设置内容保持可滚动。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.8.1 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.8.1-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.8.1-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、Provider顺序、显示器位置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。物理Windows 11多屏和不同DPI继续保留现场观察边界。
