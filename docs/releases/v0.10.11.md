# AI Token Meter 0.10.11

双平台稳定修复版；macOS build 39。修复 macOS Antigravity 暂停后无法恢复自动刷新的流程。Windows 同步版本号，产品行为保持不变。

## Antigravity 自动刷新恢复

- 暂停后先选择“单次检查额度”，完成官方 CLI 登录与额度检查。检查成功后，在五分钟内选择“恢复自动刷新”。
- 恢复选择保存成功后启用后续定时额度查询；点击恢复不会立即启动另一次 CLI 检查。
- 检查过期、取消或保存失败时保持暂停。检查忙碌时可在原有效期内再次手动选择恢复。
- Services 和悬浮详情共用恢复入口，支持英语、简体中文与繁体中文，并修正账户刷新与恢复回调并发时的暂停标记。

## 安装与更新

macOS Apple Silicon ZIP 使用 Sparkle 更新签名，应用包为 ad-hoc 签名；不声明 Developer ID 或公证。Windows x64 安装器使用 Tauri 更新签名，没有 Authenticode 发布者证书，因此 Windows SmartScreen 仍可能显示 unknown publisher；该提示与更新内容的签名验证不同。

更新不会自动清除旧暂停或登录凭据。初始服务或进程错误的根因不由本次更新推断，真实账号的额度及恢复结果以设备实际检查为准。
