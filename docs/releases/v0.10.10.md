# AI Token Meter 0.10.10

双平台稳定修复版；macOS build 38。加强 Antigravity 单次登录恢复的启动确认和进程清理。Windows 同步版本号，产品行为保持不变。

## 修复

- 登录启动明确区分“已经启动命令行工具”和“启动未能确认”，避免把不确定状态当作登录成功。
- 取消、超时和回传失败后，等待本次登录助手确认收尾；不能确认时保留恢复状态，阻止晚到的成功回执触发额度检查。
- 进程状态查询有明确时限与输出上限；查询失败或清理不确定时继续保持暂停，避免误判进程已经退出。

## 暂停与恢复

- 更新不会清除旧的 `refreshPaused=true reason=unknown`，也不会自动恢复周期刷新。用户主动完成一次官方登录和只读额度检查后，周期刷新仍保持暂停。
- 本版本不根据旧摘要推断暂停根因；真实账户的额度和 CLI 行为仍以用户设备上的结果为准。

## 平台

- macOS：Apple Silicon，macOS 14 或更新版本。
- Windows：Windows 11 x64。安装器没有 Authenticode 发布者证书，首次安装可能显示 SmartScreen 的 “unknown publisher” 提示；更新文件使用应用内更新签名校验。
- 请从项目 GitHub Release 下载并核对 SHA-256；正式资产和更新源以发布记录为准。
