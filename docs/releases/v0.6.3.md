# AI Token Meter 0.6.3

0.6.3 是 macOS Apple Silicon 与 Windows 11 x64 的稳定界面补丁版，macOS build18。本版移除macOS Settings → About中的独立作者文字行，让版本与联系入口之间更紧凑；Windows同步版本以保持双平台更新通道一致。

## macOS About 精简

- 删除独立的 `Author: Miller` 可见行及该节点占用的间距。
- 保留应用图标、名称、副标题、版本/build、Twitter、GitHub、Telegram、隐私说明和软件更新控件。
- README、MIT License和代码版权归属保持；本次界面精简不改变项目作者信息。
- Windows关于页此前已经移除作者行，本版不改变其布局或操作。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.6.3 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.6.3-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.6.3-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、用户设置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。真实Windows 11多DPI与Gemini普通OAuth额度仍保留既有现场验收边界。
