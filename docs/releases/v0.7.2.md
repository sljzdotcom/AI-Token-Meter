# AI Token Meter 0.7.2

0.7.2是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build21。本版修复Google Antigravity详情透明问题，并把Compact圆环两侧留白精确减半。

## 修复与界面调整

- macOS Google Antigravity详情恢复与其他Provider一致的深海黑蓝底板；连接状态、四个额度窗口、剩余百分比、重置时间、Retry和安装入口保持。
- Windows保持既有不透明深色详情表面和Antigravity青绿色强调色，并增加四个Provider九种详情状态的真实浏览器门禁。
- Compact逻辑宽度由65收至56.5pt/px，每侧留白由8.5减至4.25；48pt/px圆环、Logo、10pt/px间距和1至4项高度保持。
- Comfortable 108宽、折叠把手12宽、左右贴边、拖动、点击和Provider排序行为保持。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.7.2 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.7.2-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.7.2-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、用户设置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。真实Google Antigravity账号已由用户确认连接；物理Windows 11多屏、指针和不同显示器DPI仍保留现场观察边界。
