# AI Token Meter 0.5.0

## 新功能与修复

- macOS/Windows Settings 根据 CLI 状态提供醒目的安装或登录入口，已连接时显示账号与重新登录；安装完成自动重新查找。
- 安装按钮按需在线下载官方安装器，不把 Claude Code/Codex 本体塞进软件安装包；不会自动升级已有 CLI、登录或清除凭据。
- 改善 CLI 安装路径发现；区分未安装与检测暂时失败，避免误重装，保留显式 WSL/自定义路径选择。
- Windows 设置页签增加图标，顶部显示软件 Logo；仍使用系统字体。
- 两端 About 在作者 Miller 后增加带小图标的 Twitter/X（@MillerPanYue）与项目 GitHub 链接，点击后才打开系统浏览器。

## 更新与安装

已有设备：Settings → About → Check for Updates → Update Now（中文：设置 → 关于 → 检查更新 → 立即更新）。macOS 稳定/旧 Preview 与 Windows 稳定/旧 Preview 均沿用原入口，无需安装中间版本。macOS build13。

- macOS Apple Silicon：`AI-Token-Meter-0.5.0-macOS-arm64.zip`。
- Windows x64：`AI-Token-Meter-0.5.0-windows-x64-setup.exe`。
- 手动下载核对同名 SHA-256 文件；应用内更新继续验证原 Sparkle/Tauri 公钥签名。没有更新器的早期 0.1.2 需手动安装一次。

## 已知边界

macOS 仍 ad-hoc 签名、未公证；Windows 尚无 Authenticode 发布者签名，首次安装可能出现 Gatekeeper/SmartScreen 提示。Widget 证书延期，本版不含 Widget。物理多屏、Windows DPI/字体与真实账号安装流程仍需设备验收；自动化通过不代表所有真机环境已验收。
