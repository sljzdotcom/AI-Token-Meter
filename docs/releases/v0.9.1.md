# AI Token Meter 0.9.1

0.9.1是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build27。本版将悬浮条尺寸恢复为Comfortable与Compact两档，并修复产品显示设置与菜单栏/托盘摘要不同步的问题。

## 变化

- Settings → Floating Strip只保留Comfortable和Compact。
- 已保存Mini的现有用户升级后自动迁移到Compact；其他偏好与账户数据保持不变。
- Settings隐藏、恢复或排序产品后，悬浮条、macOS菜单栏面板和Windows托盘摘要使用同一可见顺序。

## 更新与安装

- macOS：Settings → About → Check for Updates → Update Now。
- Windows：Settings → About → Check for Updates → Update Now。
- macOS Apple Silicon：`AI-Token-Meter-0.9.1-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.9.1-windows-x64-setup.exe`

Windows安装器尚无Authenticode，首次安装可能出现SmartScreen `unknown publisher`提示；可用随附SHA-256核验文件。macOS包为ad-hoc签名、未公证且不含Widget，首次安装可能需要在Finder中右键打开。
