# AI Token Meter 0.9.0

0.9.0是macOS Apple Silicon与Windows 11 x64的稳定功能版，macOS build26。本版为macOS加入应用内三语言切换和Services产品Logo，并修复自动隐藏展开轮廓与Mini即时切换。

## 新增

- Settings → Appearance新增Language，可选English、简体中文和繁體中文。选择后菜单栏、五个Settings页签、悬浮条、四个Provider详情、通知和辅助功能文案立即切换并在重启后保留。
- macOS Settings → Services在Claude Code、OpenAI Codex、DeepSeek和Google Antigravity名称前显示对应Logo；图标适配浅色与深色外观。

## 修复

- macOS开启自动隐藏后，悬停展开使用与常驻展开相同的精确尺寸和圆润轮廓，不再因从收起窗口拉伸而出现尖角。
- 在自动隐藏转换期间选择Comfortable、Compact或Mini，会立即应用最后一次设置；Mini无需等待再次收起和悬停。

## 更新与安装

- macOS：Settings → About → Check for Updates → Update Now。
- Windows：Settings → About → Check for Updates → Update Now。
- macOS Apple Silicon：`AI-Token-Meter-0.9.0-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.9.0-windows-x64-setup.exe`

Windows随本版同步版本和稳定更新通道，产品功能与0.8.2保持一致。Windows安装器尚无Authenticode，首次安装可能出现SmartScreen `unknown publisher`提示；可用随附SHA-256核验文件。macOS包为ad-hoc签名、未公证且不含Widget，首次安装可能需要在Finder中右键打开。
