# AI Token Meter 0.10.7

稳定修复版；目标为 macOS build 35。Antigravity未知暂停新增一次性受控恢复入口；Windows运行行为保持不变。

## 修复

- 当旧诊断显示 `refreshPaused=true reason=unknown` 时，可由用户主动开始一次官方交互登录，再执行一轮只读额度检查。
- 成功的单次检查不会解除持久暂停或恢复周期刷新；失败、取消、超时或无效回执不会启动额度读取。
- 登录脚本先非阻塞打开完成回执 FIFO，再有限时等待；没有回执写入者时会退出并清理临时 FIFO，不会卡住 Terminal。

## 平台说明

- macOS：登录仍由官方 CLI 与系统浏览器/授权流程完成；是否能成功登录取决于用户账号和官方服务。此功能只恢复一次额度检查，不代表后台自动刷新已恢复。
- Windows：运行行为不变，仅同步版本号及签名发布资产。
- Windows安装程序没有 Authenticode 发布者证书，首次安装可能显示 SmartScreen “unknown publisher”提示；请从项目 GitHub Release 下载并核对 SHA-256。

## 安全边界

- 不清除已保存的持久暂停状态，不重放 OAuth，不读取或保存账号、令牌或 CLI 输出。
- 发布验证不登录真实账号或运行现场 CLI。

签名资产、校验值和三个更新源在发布后由[发布记录](../development/2026-10-07-v0.10.7-release.md)补充。
