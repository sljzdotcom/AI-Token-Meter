# AI Token Meter 0.10.4

稳定修复版；macOS build 32。macOS Antigravity额度采集在异常后会安全暂停，Windows运行行为保持不变。

## 修复

- Antigravity额度采集发生失败、超时或取消后，会保存暂停状态。应用启动、定时刷新、唤醒、普通手动检查和 Retry 均不会重新启动额度 CLI。
- 用户可以在 macOS Settings → Services 显式选择 **Sign in to Antigravity**。登录终端结束后，本次应用会用一次性回执触发一轮 headless 额度检查；无效或重复回执不会恢复采集。
- 超时或取消时，应用会结束本次 `agy` 启动的子进程组，避免遗留进程继续工作。其他用户启动的浏览器或 CLI 不受影响。
- 额度查询继续使用官方 `agy -p /usage` headless 接口，不操作 Google 账户、凭据或 Keychain。
- Windows 安装器目前没有 Authenticode 发布者证书，因此首次安装仍可能出现 SmartScreen “unknown publisher”提示；请从本项目 GitHub Release 下载并核对 SHA-256，应用内更新仍使用 Tauri 签名校验。

## 平台与验证范围

- macOS：包含异常暂停、显式恢复和进程清理修复。
- Windows：仅同步共享应用版本；运行行为保持不变。
- 自动化验证不能替代用户报告设备上的现场验收。首次更新后请观察 Antigravity 的设置状态和浏览器行为；真实 CLI 登录继续由用户在官方终端流程中自行完成。
