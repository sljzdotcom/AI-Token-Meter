# AI Token Meter 0.2.2

AI Token Meter 0.2.2 修复从 Settings 启动应用内更新时，Sparkle 安装窗口可能被遮挡、界面看似一直停在 Preparing 的问题。

## 修复

- 点击 **Update Now** 后，AI Token Meter 会让 Settings 临时隐藏并激活应用，再进入 Sparkle 的标准安装流程。
- 下载完成后的 **Install and Relaunch** 窗口会保持可见，不再需要从 Window 菜单手动寻找。
- 只处理 Settings 窗口；普通应用窗口、详情窗口和更新状态机保持原有行为。

## 安装与更新

- 已安装 `0.2.0` 或 `0.2.1`：Settings → About → **Check for Updates**，发现 `0.2.2` 后点击 **Update Now**。
- `0.1.2` 或更早版本：下载 `AI-Token-Meter-0.2.2-macOS-arm64.zip` 与同名 `.sha256`，验证后手动替换一次。

当前发行支持 Apple Silicon 与 macOS 14+，为 ad-hoc signed、not notarized。首次运行如果 macOS 阻止，请在 Finder 中右键 App 并选择“打开”。

## 安全与隐私

- 更新归档继续使用 Sparkle EdDSA 签名；签名、版本、build 或长度不匹配时不会替换当前 App。
- 应用仍只在用户点击 **Check for Updates** 后访问 GitHub，不做后台检查或静默安装。
- 仍保留 Sparkle 的安装确认和 **Install and Relaunch** 明确操作；本次修复不新增权限、网络端点、凭据读取或数据持久化。

完整变化见 [CHANGELOG](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/CHANGELOG.md)，安装与排障见[用户指南](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/docs/user-guide/getting-started.md)和[故障排查](https://github.com/sljzdotcom/AI-Token-Meter/blob/main/docs/user-guide/troubleshooting.md)。
