# AI Token Meter 0.5.1

## Windows 修复

- 修复已安装并登录的 npm Codex 因 Node 位于另一个目录而显示“未安装”；显式定位官方入口与 Node，保留已有登录信息。
- 统一账户、额度与登录的 CLI 检测；启动失败不再误报未安装。
- 修复手工保存 Codex CLI 路径后再次检测失效。
- Claude Code 增加“初始化额度读取”：使用专用工作区，不自动信任主目录或重复登录。若已登录但额度仍需设置，请点击该按钮，在官方终端完成必要确认，再点击“检查状态”。
- 手动检查可恢复额度读取，自动检查不重复请求；限流等待仍保留。

## 更新方法

Windows：设置 → 关于 → 检查更新 → 立即更新。稳定版与旧 Preview 沿用原更新入口、公钥与应用身份，保留设置和凭据，无需中间版本。

macOS 同步为 0.5.1/build14，功能不变，继续使用原更新通道。

- Windows x64：`AI-Token-Meter-0.5.1-windows-x64-setup.exe`。
- macOS Apple Silicon：`AI-Token-Meter-0.5.1-macOS-arm64.zip`。
- 手动下载可核对同名 SHA-256；应用内更新验证原 Tauri/Sparkle 签名。

## 边界

Windows 无 Authenticode 发布者签名，首次手动安装可能遇到 SmartScreen；更新签名不等于发布者证书。macOS 仍 ad-hoc、未公证、不含 Widget。自动化覆盖原生 Windows 进程和 npm/Node 分离目录，但用户真实账号额度与工作区确认需安装新版后验收。
