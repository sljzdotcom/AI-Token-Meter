# AI Token Meter 0.6.0

0.6.0 为 macOS Apple Silicon 与 Windows 11 x64 的同版本稳定更新，macOS build 15。本版新增 Gemini，并交付刷新间隔、浮动条和关于页的累积改进。

## Gemini

- 新增青绿色 Gemini 按钮、详情和 Services 配置；四项服务可以显示、隐藏和调整顺序。
- 新用户默认看到 Claude Code、OpenAI Codex、DeepSeek 和 Gemini。升级用户保留原三项顺序，并把 Gemini 追加为隐藏项，避免升级后界面突然改变。
- 从官方 Gemini CLI 0.58.0 的交互式 `/model` 界面读取普通 Google OAuth 账户当前展示的模型档位额度、重置说明、CLI 版本与采集时间。
- 安装、登录、版本、认证模式或输出不受支持时显示可执行的状态提示；失败时保留最近成功快照。Windows 首期只支持原生 Gemini CLI。

## 其他改进

- macOS 设置 → 监测的用量刷新间隔可编辑并保存，范围为 30 秒至 24 小时；新间隔会重新安排等待，同时保留采集和限流退避。
- macOS 与 Windows 浮动条展开态移除顶部横线，背景拖动、Provider 点击和折叠态竖线保持。
- 两端关于页增加 Telegram `@sljzdotcom` 图标链接。Windows 移除作者整行和可见社交标题，保留 Twitter、GitHub 和 Telegram 图标。
- Windows 发现新版时使用深红色粗体提示，中英文同步。

## 更新方法

macOS：设置 → 关于 → 检查更新，然后按 Sparkle 提示安装并重新启动。

Windows：设置 → 关于 → 检查更新 → 立即更新。稳定版与旧 Preview 入口使用同一份 0.6.0 Windows 更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.6.0-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.6.0-windows-x64-setup.exe`

手动下载时可核对同名 SHA-256 文件；应用内更新继续验证原 Sparkle/Tauri 更新签名。应用身份、更新地址、公钥、设置和本机凭据存储保持兼容。

## 使用边界

Gemini 本版只支持官方 CLI 0.58.0 的普通 Google OAuth 模式，不覆盖 API Key、Vertex AI、企业账户、外部认证或 Windows WSL。应用只驱动官方 CLI 并解析终端可见额度，不读取或保存 Gemini 凭据。本轮自动化没有登录真实 Gemini 账号，也没有消耗真实额度。

Windows 安装包暂未使用 Authenticode 发布者证书，首次手动安装可能出现 SmartScreen 的 unknown publisher（未知发布者）提示。macOS 包使用 ad-hoc 签名、未公证且不含 Widget；首次手动打开可能需要在 Finder 中右键选择“打开”。这些分发边界不影响应用内更新签名校验。
