# AI Token Meter 0.3.0-preview.3

AI Token Meter `0.3.0-preview.3` 正式交付 `REQ-20260904-006`：修复 Windows DeepSeek 官网历史窗口、同步反馈、详情与 Settings 密度以及字体下拉可读性。macOS 功能和视觉保持不变，两平台继续使用同一版本和同一个 GitHub Release。

## 主要变化

- Windows 打开 DeepSeek 详情时不再自动创建空白官网窗口；只有点击 **Sync official history** 才启动隔离的官方 WebView2 会话。
- DeepSeek 官网窗口支持隐藏加载、ready 后置前、重复请求复用、用户关闭、失败恢复、超时清理与成功后自动销毁。
- 详情页显示 opening、active、failed 等固定脱敏同步状态；同步期间暂停详情自动隐藏，失败后可重新尝试。
- Windows 三个 Provider 详情和 Settings 使用更紧凑的专属字号与间距；macOS 样式不变。
- Windows Settings 的 Display font 原生下拉框固定使用白底深色文字，解决选项只有悬停时才可见的问题。
- DeepSeek 官网桥继续只接受精确官方 HTTPS origin、短期 nonce 和当前会话代次；网页正文、Cookie、Authorization、API Key 与个人账号信息不会进入事件或业务日志。

## 下载与安装

在 [GitHub Release](https://github.com/sljzdotcom/AI-Token-Meter/releases/tag/v0.3.0-preview.3) 下载：

- macOS Apple Silicon：`AI-Token-Meter-0.3.0-preview.3-macOS-arm64.zip` 与同名 `.sha256`；
- Windows 11 x64：`AI-Token-Meter-0.3.0-preview.3-windows-x64-setup.exe` 与同名 `.sha256`。

macOS 包仍为 ad-hoc signed、not notarized；首次运行可能需要在 Finder 中右键选择“打开”。Windows 安装器仍没有 Authenticode 发布者证书，SmartScreen 可能显示 unknown publisher；只从本仓库下载并核对 SHA-256。应用内 Windows 更新另由 Tauri minisign 验证。

## 更新说明

- 已安装 Windows Preview 的机器可在 Settings → About 点击 **Check for Updates**，发现 `0.3.0-preview.3` 后点击 **Update Now**。
- Windows 更新器会验证 Tauri minisign 签名，不会静默安装。
- macOS Preview 仍不进入稳定 `appcast.xml`，需要从本 Release 手动下载；macOS 稳定更新通道继续保持 `0.2.2`。

## 真机验收重点

- 点击 DeepSeek 圆环时只出现详情，不出现第二个空白窗口；
- 点击 **Sync official history** 后官网窗口能够加载、置前、关闭，并在成功或失败后恢复详情；
- 最近 30 天历史同步成功后在原生详情中显示；
- Claude Code、OpenAI Codex、DeepSeek 详情标题与正文在 Windows 上大小合理；
- Settings 使用系统字体，Display font 下拉框全部选项清晰可见；
- 从 `0.3.0-preview.2` 原位更新后保留设置、Credential Manager 与浮动条位置。

自动化验证不能替代交互式 Windows 11/WebView2 登录和视觉验收；这些结果继续记录在需求台账中。
