# AI Token Meter 0.8.2

0.8.2是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build25。本版让悬浮条密度设置立即生效，并修正左右贴边时的圆角和反向肩弧。

## 修复

- 在Settings切换Comfortable、Compact或Mini后，已展开悬浮条会立即调整为新尺寸，不再需要先等待收起再重新悬停。
- 左贴边时，暴露侧的右上角和右下角恢复为圆润轮廓；右贴边保持严格镜像。
- 加强贴屏侧上下反向肩弧：Mini和Compact使用70pt/px肩深，Comfortable使用88pt/px肩深，30pt/px弧段在左右和上下方向保持镜像。
- Windows设置保存会等待对应原生窗口调整完成；快速连续切换、拖拽延后、失败和超时不会让旧尺寸覆盖最新偏好。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.8.2 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.8.2-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.8.2-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、Provider顺序、显示器位置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。物理Windows 11多屏和不同DPI继续保留现场观察边界。
