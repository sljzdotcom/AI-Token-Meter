# AI Token Meter 0.7.1

0.7.1 是 macOS Apple Silicon 与 Windows 11 x64 的稳定功能版，macOS build20。本版把第四项服务迁移为 Google Antigravity，并收紧Compact浮动条与macOS菜单面板品牌布局。

## Google Antigravity

- 第四项服务改名为Google Antigravity，使用官方`agy -p /usage`读取额度。
- 展示Gemini与Claude/GPT的五小时和每周四个窗口；卡片显示剩余百分比，进度环继续表达已用比例。
- macOS与Windows同步安装、登录、详情、缓存迁移和Widget可见名称。
- 内部`gemini`兼容标识继续保留既有排序、隐藏和历史缓存。
- 当前采集不再调用旧`gemini` CLI或交互式`/model`会话。

## 界面调整

- Compact浮动条宽度由78收至65pt/px，48pt/px圆环、环间距和1至4项高度保持；左右贴边、拖动、点击和折叠行为不变。
- macOS菜单面板标题区的应用Logo由32pt放大至40pt，面板宽度、标题、副标题、间距和系统菜单栏图标保持。

## 可靠性

- Windows前端测试文件改为串行调度，保留每项5秒防挂死上限，避免签名发布runner上的jsdom冷启动资源竞争影响发布门禁；产品行为和用户数据不变。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.7.1 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.7.1-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.7.1-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、用户设置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。真实Google Antigravity账号和物理Windows 11多DPI交互仍保留现场验收边界。
