# AI Token Meter 0.7.3

0.7.3是macOS Apple Silicon与Windows 11 x64的稳定界面更新，macOS build22。本版重新设计贴边浮动条的轮廓与悬停交互，并恢复Google Antigravity详情强调色。

## 新功能与修复

- Compact展开宽度采用65pt/px，48pt/px圆环保持不变；新的上下S形弧肩和底部Settings弧区完整包住1至4个Provider。
- 闲置时收成7pt/px可见细条，指针进入后展开；快速进出会取消旧计时，过渡中不会出现圆环悬空或超出背景。
- 底部齿轮直接打开Appearance；显示延迟和收起延迟可分别设置，默认150ms与800ms并立即保存。
- Google Antigravity详情恢复青绿色标题、额度值与进度强调，同时保留深海不透明底板和原有数据语义。

## 更新方法

macOS：Settings → About → Check for Updates，然后按Sparkle提示安装并重新启动。

Windows：Settings → About → Check for Updates → Update Now。稳定版与旧Preview入口使用同一份0.7.3 Windows更新清单。

- macOS Apple Silicon：`AI-Token-Meter-0.7.3-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.7.3-windows-x64-setup.exe`

手动下载时可核对同名SHA-256文件；应用内更新继续验证既有Sparkle/Tauri更新签名。版本升级不改变应用身份、公钥、Provider顺序、显示器位置或凭据存储位置。

## 使用边界

Windows安装包暂未使用Authenticode发布者证书，首次手动安装可能出现SmartScreen的unknown publisher提示。macOS包使用ad-hoc签名、未公证且不含Widget；首次手动打开可能需要在Finder中右键选择“打开”。物理Windows 11多屏和不同DPI继续保留现场观察边界。
