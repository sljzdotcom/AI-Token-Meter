# AI Token Meter 0.3.0-preview.1

AI Token Meter `0.3.0-preview.1` 是 Windows 浮动条视觉与贴边稳定性修复版。macOS 功能和已确认视觉不变，两平台继续使用同一版本和同一个 GitHub Release。

## 主要变化

- Windows 浮动条改用与 macOS 相同的四段 Bezier 外形，恢复上下反向肩部，并在左/右贴边时严格镜像。
- 删除 CSS 粗多边形与 Win32 GDI Region 的双重可见裁剪，改由 WebView2 的 SVG 路径单一抗锯齿绘制。
- 关闭 Windows 无边框窗口阴影与 DWM 外框，消除透明窗口外侧 1px 白框和上下白条。
- 深海背景直接覆盖完整外形，不再由分离的伪元素拼接肩部。
- 拖动开始至鼠标释放期间暂停显示器自动恢复；释放后仅吸附并保存一次，启动轮询不再重复移动窗口。

## 下载与安装

在 [GitHub Release](https://github.com/sljzdotcom/AI-Token-Meter/releases/tag/v0.3.0-preview.1) 下载：

- macOS Apple Silicon：`AI-Token-Meter-0.3.0-preview.1-macOS-arm64.zip` 与同名 `.sha256`；
- Windows 11 x64：`AI-Token-Meter-0.3.0-preview.1-windows-x64-setup.exe` 与同名 `.sha256`。

macOS 包仍为 ad-hoc signed、not notarized；首次运行可能需要在 Finder 中右键选择“打开”。Windows 安装器仍没有 Authenticode 发布者证书，SmartScreen 可能显示 unknown publisher；只从本仓库下载并核对 SHA-256。应用内 Windows 更新另由 Tauri minisign 验证。

## 更新说明

- Windows `0.3.0-preview.0` 使用独立 Preview feed，可在 Settings → About 手动检查并升级到本版本。
- macOS Preview 不进入稳定 `appcast.xml`，需要从 Release 手动下载；稳定更新通道仍保持 `0.2.2`。
- 两个平台都不会静默安装更新。

## 仍需真机确认

- Windows 100%/125%/150%/200% DPI 的最终边缘像素观感；
- 左右真实指针拖动、多显示器拔插、重启位置恢复；
- `preview.0 → preview.1` 原位升级后的设置和 Credential Manager 保留；
- 错误签名 Preview feed 必须拒绝替换旧版。

这些项目需要交互式 Windows 11 会话，CI 构建和单元测试不会冒充真机验收。
