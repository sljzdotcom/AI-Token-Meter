# AI Token Meter 0.3.0-preview.2

AI Token Meter `0.3.0-preview.2` 修复 Windows 启动时额外出现空白 Windows Terminal 的问题。macOS 功能和视觉保持不变，两平台继续使用同一版本和同一个 GitHub Release。

## 主要变化

- Windows 主程序改为 GUI subsystem；从安装器、开始菜单或资源管理器启动时，只创建浮动条与系统托盘，不再申请控制台窗口。
- Windows CI 和正式 Release 新增真实 PE Header 检查；主 `.exe` 不是 subsystem `2` 时构建会被拒绝。
- 保留 `0.3.0-preview.1` 已加入的 macOS 同源浮动条轮廓、无白边合成、深海背景和稳定拖动/贴边策略。

## 下载与安装

在 [GitHub Release](https://github.com/sljzdotcom/AI-Token-Meter/releases/tag/v0.3.0-preview.2) 下载：

- macOS Apple Silicon：`AI-Token-Meter-0.3.0-preview.2-macOS-arm64.zip` 与同名 `.sha256`；
- Windows 11 x64：`AI-Token-Meter-0.3.0-preview.2-windows-x64-setup.exe` 与同名 `.sha256`。

macOS 包仍为 ad-hoc signed、not notarized；首次运行可能需要在 Finder 中右键选择“打开”。Windows 安装器仍没有 Authenticode 发布者证书，SmartScreen 可能显示 unknown publisher；只从本仓库下载并核对 SHA-256。应用内 Windows 更新另由 Tauri minisign 验证。

## 更新说明

- Windows Preview 使用独立 Preview feed，可在 Settings → About 手动检查并升级到本版本。
- macOS Preview 不进入稳定 `appcast.xml`，需要从 Release 手动下载；稳定更新通道仍保持 `0.2.2`。
- 两个平台都不会静默安装更新。

## 仍需真机确认

- Windows 启动时只显示浮动条与系统托盘，不再打开标题为 “AI Token Meter” 的 Windows Terminal；
- `preview.1 → preview.2` 原位升级后设置、Credential Manager 与浮动条位置保持；
- 既有 100%/125%/150%/200% DPI、左右拖动和多显示器验收项。

自动化已验证 PE GUI subsystem，但不会把 CI 冒充为交互式桌面验收。
