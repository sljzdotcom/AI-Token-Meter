# AI Token Meter 0.10.1

0.10.1是macOS Apple Silicon与Windows 11 x64的稳定修复版，macOS build29。本版让Google Antigravity的用量展示聚焦Gemini，并补充来自官方CLI的模型与版本信息。

## 变化

- Antigravity详情、悬浮条圆环、菜单栏/托盘摘要和用量提醒只采用Gemini Five Hour与Weekly两个额度窗口。
- Antigravity详情不再显示Claude/GPT共享额度；Claude Code与OpenAI Codex继续作为独立服务展示。
- 详情在信息可用时显示当前Gemini模型、动态可用Gemini模型数量与系列、Antigravity CLI版本和检查时间。
- CLI补充信息独立容错；读取模型或目录失败不会影响已成功读取的Gemini额度。
- 旧四窗口缓存升级后自动按Gemini额度重新计算，异常、第三方或可能含敏感内容的模型文本不会进入界面或缓存。

## 更新与安装

- macOS：Settings → About → Check for Updates → Update Now。
- Windows：Settings → About → Check for Updates → Update Now。
- macOS Apple Silicon：`AI-Token-Meter-0.10.1-macOS-arm64.zip`
- Windows x64：`AI-Token-Meter-0.10.1-windows-x64-setup.exe`

Windows安装器尚无Authenticode，首次安装可能出现SmartScreen `unknown publisher`提示；可用随附SHA-256核验文件。macOS包为ad-hoc签名、未公证且不含Widget，首次安装可能需要在Finder中右键打开。
