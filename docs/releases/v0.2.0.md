# AI Token Meter 0.2.0

AI Token Meter 0.2.0 为 Settings → About 增加安全的 GitHub 应用内更新，同时保留“只有用户操作才联网”的本地优先边界。

## 新增

- **Check for Updates**：手动读取项目稳定版更新清单。
- **Update Now**：发现更高版本后，由用户明确启动下载和安装。
- 使用 Sparkle 2.9.4 标准界面完成更新，并在替换 App 前验证 EdDSA 发布签名。
- 完整嵌入 Sparkle framework、Updater、Autoupdate 和 XPC helper，支持下载后原位替换并重新启动。

## 安装

下载以下两个资产：

- `AI-Token-Meter-0.2.0-macOS-arm64.zip`
- `AI-Token-Meter-0.2.0-macOS-arm64.zip.sha256`

验证 SHA-256、解压，将 `AI Token Meter.app` 移到 `/Applications`。当前发行支持 Apple Silicon 和 macOS 14+，为 ad-hoc signed、not notarized；首次运行如果 macOS 阻止，请在 Finder 中右键 App 并选择“打开”。

`0.1.2` 尚未包含应用内更新器，所以升级到 `0.2.0` 需要手动替换这一次。从 `0.2.0` 开始，后续稳定版本可在 Settings → About 内完成手动检查与更新。

## 安全与隐私

- 应用启动和后台驻留不会检查更新；只有点击 **Check for Updates** 才访问 GitHub。
- 只有点击 **Update Now** 才下载并进入安装流程，不静默安装。
- App 只包含公开验证键；生产签名私钥保存在维护者 macOS Keychain 中，不进入仓库、日志或 Release。
- 签名、版本、build、归档长度或下载校验不通过时，当前 App 保持不变。

## 已知边界

- 此 Release 不包含需要 Apple Development 证书的桌面 Widget。
- 尚未使用 Developer ID 或 Apple notarization；应用内 EdDSA 验证不替代 Apple 的发行身份与公证。
- OpenAI Codex 在 nvm 环境的跨 Mac 界面结果仍以用户设备复验为准；0.2.0 保留 0.1.2 已实现的发现与 Node PATH 修复。

完整变化见 [CHANGELOG](../../CHANGELOG.md)，安装与排障见[用户指南](../user-guide/getting-started.md)和[故障排查](../user-guide/troubleshooting.md)。
