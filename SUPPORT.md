# Support

## 使用问题与故障

请先查看：

- [安装与首次使用](docs/user-guide/getting-started.md)
- [服务与指标说明](docs/user-guide/providers.md)
- [故障排查](docs/user-guide/troubleshooting.md)

仍无法解决时，请使用 GitHub Issue 的 Bug report 模板，并提供 AI Token Meter 版本、macOS 版本、Mac 芯片、复现步骤以及已经脱敏的错误信息。

## 功能建议

请使用 Feature request 模板，说明使用场景、预期行为和为什么现有功能无法满足。实现前会先评估隐私、数据来源稳定性和 macOS 平台限制。

## 安全问题

不要公开提交 API Key、Token、Cookie、CLI 凭证、账户响应或未脱敏截图。安全问题请按照 [Security Policy](SECURITY.md) 通过仓库的 [Security → Report a vulnerability](https://github.com/sljzdotcom/AI-Token-Meter/security/advisories/new) 私密报告。

## Support in English

Read the user guides first, then open a GitHub issue with the provided template. Include the app version, macOS version, Apple Silicon model, reproducible steps, and redacted diagnostics. Report security issues privately according to [SECURITY.md](SECURITY.md); never post credentials or account data in public.
